## Page 16 - Consonants `[p] [t] [b] [d]`

[[法语语音笔记.pdf#page=16|View original PDF · Page 16]]

> [!note] 规则
> 清辅音 `[p] [t]`: 后接元音不送气，需要浊化。  
> 浊辅音: `[b] [d]`.

| Contrast + handwritten cue       |
| -------------------------------- |
| **pipe - Bible** (`bip / bible`) |
| **passe - basse** (`bus / bus`)  |
| **tousse - douce** (`dus / dus`) |
| **tate - date** (`da + t`)       |

## Page 17 - Vowel `[e]` ei (letter A) · 元音5

[[法语语音笔记.pdf#page=17|View original PDF · Page 17]]

> [!example] Examples
> **été, fée, épée** (`é → A` note at top)  
> **effet, essai, ellipse**  
> **laisser, répéter**  
> **des, mes**  
> **chez, allez**

> [!note] 拼写规则
> - 字母 **é**
> - **e** 于词首后接 `-ff, -ss, -ll`
> - **er** 在词末
> - **es** 在单音节词末
> - **ez** 在词末

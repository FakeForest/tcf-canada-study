# Lesson 2 - Qui est-ce ?

> [!info] 复习重点
> **课文 + 单词 + 语法**。法语旁边的英文式拼写保留为你的记忆提示；被划掉的字母表示不发音。

## 课文

### 对话：这是谁？

| 法语 | 中文 |
|---|---|
| **Qui est-ce ?** | 这是谁？ |
| **C'est Naoko, non ?** | 这是 Naoko，对吗？ |
| **Naoko ?** | Naoko？ |
| **Oui, Naoko Yamada.** | 是的，Naoko Yamada。 |
| **Elle est étudiante.** | 她是大学生。 |
| **Elle est sympa ?** | 她人好吗？ |
| **Oui.** | 是的。 |
| **Elle est dans le cours de français.** | 她在法语课上。 |
| **Elle est japonaise.** | 她是日本人。 |
| **Elle habite en France ou au Japon ?** | 她住在法国还是日本？ |
| **Elle habite en Suisse, à Genève.** | 她住在瑞士日内瓦。 |

### 复用句型

| 法语 | 中文 |
|---|---|
| **Il / Elle s'appelle...** | 他 / 她叫…… |
| **Il / Elle est français(e).** | 他 / 她是法国人。 |
| **Il / Elle est photographe / étudiant(e).** | 他 / 她是摄影师 / 大学生。 |
| **Il / Elle habite à Paris, en France.** | 他 / 她住在法国巴黎。 |

### 数字

`60` soixante · `61` soixante et un / une · `69` soixante-neuf · `70` soixante-dix · `71` soixante et onze · `72` soixante-douze · `79` soixante-dix-neuf

## 语法

### 1. 定冠词: `le`, `la`, `l'`

| 阳性 | 阴性 |
|---|---|
| le / l' | la / l' |
| le cours | la femme |
| l'étudiant | l'étudiante |
| l'homme | l'héroïne |

- 定冠词放在名词前，提示名词的阴阳性和单复数，并与名词配合。
- 来源例子里，定冠词可以指已经提到的人/物、双方都知道的人/物、泛指类别，或指整个类别。

> 来源: [[你好法语A1第一单元.pdf#page=10|你好法语A1第一单元.pdf - 第 10-11 页]]

PPT 给出完整的定冠词形式：

| 冠词 | 用在什么前面 | 例子 |
|---|---|---|
| **le** | masculine singular | **le cours**, **le Japon** |
| **la** | feminine singular | **la table**, **la Chine** |
| **l'** | 元音或哑音 `h` 开头的单数名词 | **l'ami**, **l'amie** |
| **les** | 复数名词，不分阴阳性 | **les cours**, **les tables**, **les amis** |

PPT 中定冠词的常见用法：

- 回指前面已经提到的东西: **C'est un livre. Le livre est intéressant.**
- 表示独一无二或普遍已知的事物: **La Chine est très belle.**
- 用于被关系/所属限定的名词前: **C'est le papa de Paul.**
- 表示整个类别: **J'aime le thé.**
- 表示说话双方都知道的东西: **Le professeur est sympa.**

### 2. 名词阴性形式

| 阳性            | 阴性              |
| ------------- | --------------- |
| étudiant      | étudiante       |
| directeur     | directrice      |
| danseur       | danseuse        |
| boulanger     | boulangère      |
| juif          | juive           |
| informaticien | informaticienne |

> 来源: [[你好法语A1第一单元.pdf#page=12|你好法语A1第一单元.pdf - 第 12-14 页]]

PPT 按词尾整理职业/人物名词的阴性变化：

| 阳性词尾 | 阴性变化 | 例子 |
|---|---|---|
| 基本规则 | 加 **-e** | **étudiant → étudiante** |
| 来自名词的 **-teur** | **-trice** | **acteur → actrice** |
| 来自动词的 **-eur** | **-euse** | **chanteur → chanteuse** |
| **-er** | **-ère** | **boulanger → boulangère** |
| **-f** | **-ve** | **juif → juive** |
| **-ien** | **-ienne** | **musicien → musicienne** |
| already ends in **-e** | same form | **secrétaire → secrétaire** |

PPT 特别提示：

- 有些职业名词传统上不常用阴性形式，例如 **professeur**，PPT 例子给出 **femme professeur**。
- 有些配对名词本身是不同词，例如 **monsieur / madame**。

### 3. 国家与城市名称

| 地名类型     | 来源例句                                     |
| -------- | ---------------------------------------- |
| 辅音开头的国家名 | J'habite **au Japon / au Canada**.       |
| 元音开头的国家名 | J'habite **en Iran**.                    |
| 阴性国家名    | J'habite **en France / en Chine**.       |
| 城市名      | J'habite **à Paris / à Rome / à Tokyo**. |

> [!tip] 来源提醒
> **au = à + le**. 来源中把它用于辅音开头的阳性国家名，例如 **au Japon**。

> 来源: [[你好法语A1第一单元.pdf#page=15|你好法语A1第一单元.pdf - 第 15-17 页]]

PPT 给出更细的国家/城市介词规则：

| 地名类型 | 介词 | 例子 |
|---|---|---|
| 阴性单数国家名，常以 **-e** 结尾 | **en** | **en France**, **en Chine**, **en Suisse** |
| 元音开头的阳性单数国家名 | **en** | **en Irak** |
| 辅音开头的阳性单数国家名 | **au** | **au Canada**, **au Japon**, **au Portugal** |
| 复数国家名 | **aux** | **aux États-Unis**, **aux Pays-Bas**, **aux Maldives** |
| 城市名 | **à** | **à Paris**, **à Shanghai**, **à La Baule** |
| 名称中带 **le** 的城市 | **au** | **au Havre**, **au Caire** |
| PPT 例子中不带冠词的国家名 | **à** | **à Madagascar**, **à Cuba**, **à Singapour** |

PPT 例外提示：大多数以 **-e** 结尾的国家名是阴性，但 **le Mexique** 是阳性。

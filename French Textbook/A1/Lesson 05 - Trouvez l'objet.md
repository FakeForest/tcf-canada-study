# Lesson 5 - Trouvez l'objet

> [!info] 复习重点
> **课文 + 单词 + 语法**。这一课用物品名称和位置词来描述房间里东西的位置。

## 课文

### 对话：找物品

| 法语 | 中文 |
|---|---|
| **Son chapeau et son blouson, c'est ça ?** | 是他的帽子和夹克，对吗？ |
| **Oui, son chapeau et son blouson.** | 对，他的帽子和夹克。 |
| **Ils sont dans la chambre de Mélanie, sous l'étagère à côté de la fenêtre.** | 它们在 Mélanie 的房间里，在窗户旁边的架子下面。 |
| **L'étagère avec des livres, à gauche de la fenêtre ?** | 那个有书的架子，在窗户左边的吗？ |
| **Non !** | 不是！ |
| **L'étagère contre le mur, à droite de la fenêtre... sous les affiches !** | 是靠墙的那个架子，在窗户右边……在海报下面！ |
| **Oh là là !** | 哎呀！ |
| **À droite de... Ah oui !** | 在……右边。啊，对！ |
| **Sur la chaise, il y a un blouson et un chapeau.** | 椅子上有一件夹克和一顶帽子。 |
| **Voilà ! C'est ça !** | 就是它！对了！ |

### 位置词

| 法语 | 中文 |
|---|---|
| **sur** | 在……上面 |
| **sous** | 在……下面 |
| **à côté de** (`beside`) | 在……旁边 |
| **devant** (`in front of`) | 在……前面 |
| **derrière** (`behind`) | 在……后面 |
| **dans** | 在……里 |
| **à gauche de / à droite de** | 在……左边 / 右边 |

> [!note] 手写例句
> - **Le chien est devant la porte.**
> - **Le chien est dans la boîte.**

## 语法

### 1. 单复数冠词

| 单数 | 复数 |
|---|---|
| le voisin / la voisine / l'étudiant(e) | les voisins / les voisines / les étudiant(e)s |
| un voisin / une voisine | des voisins / des voisines |

### 2. 缩合冠词

| 组合 | 结果 | 例子 |
|---|---|---|
| à + le | **au** | Je vais **au** Canada. |
| à + les | **aux** | Il habite **aux** États-Unis. |
| à + la | **à la** | Elle va **à la** bibliothèque. |
| de + le | **du** | C'est le manteau **du** directeur. |
| de + les | **des** | Elle vient **des** bureaux des professeurs. |
| de + la | **de la** | Le cinéma se trouve **de la** rue. |
| de + l' | **de l'** | Ils se rencontrent **sur la place de l'Opéra**. |

> 来源: [[你好法语A1第二单元.pdf#page=7|你好法语A1第二单元.pdf - 第 7 页]]

PPT 提醒：

| With `à` | With `de` |
|---|---|
| **à + le = au** | **de + le = du** |
| **à + les = aux** | **de + les = des** |
| **à + la = à la** | **de + la = de la** |
| **à + l' = à l'** | **de + l' = de l'** |

PPT 还提醒：**des** 不一定都是缩合冠词；它也可以是不定冠词的复数形式，例如 **des livres**。

### 3. 名词复数

| 单数 | 复数 |
|---|---|
| homme | hommes |
| livre | livres |
| cheval | chevaux |
| nez | nez |
| noyau | noyaux |
| chapeau | chapeaux |
| feu | feux |

> 来源: [[你好法语A1第二单元.pdf#page=8|你好法语A1第二单元.pdf - 第 8 页]]

PPT 里的详细复数规则：

| 规则 | 例子 |
|---|---|
| 基本规则：加 **-s** | **un livre → des livres**, **la table → les tables** |
| final **s**, **x**, **z**: no change | **un tapis → des tapis**, **la noix → les noix** |
| final **-au**, **-eau**, **-eu**: add **-x** | **un noyau → des noyaux**, **le chapeau → des chapeaux**, **mon cheveu → mes cheveux** |
| final **-al**: changes to **-aux** | **un journal → des journaux**, **le cheval → les chevaux** |

PPT 提示：很多名词的单数和复数读音相同。

### 4. `que` 和 `qu'est-ce que`

| 问法 | 例句 |
|---|---|
| `que / quoi` | **C'est quoi ?** |
| `qu'est-ce que` | **Qu'est-ce que c'est ?** |
| `que / quoi` | **Que faites-vous dans la vie ?** |
| `qu'est-ce que` | **Qu'est-ce que vous faites dans la vie ?** |

> 来源: [[你好法语A1第二单元.pdf#page=9|你好法语A1第二单元.pdf - 第 9-10 页]]

PPT groups questions by register:

| 类型 | 更口语 | 口语 / 书面 | 更书面 |
|---|---|---|---|
| yes/no question | **Tu aimes la musique ?** | **Est-ce que tu aimes la musique ?** | **Aimes-tu la musique ?** |
| 特殊疑问句 | **Tu aimes quoi ?** | **Qu'est-ce que tu aimes ?** | **Qu'aimes-tu ?** |

**que** 不在句首时通常变成 **quoi**：

- **C'est quoi ?**
- **Tu aimes quoi ?**

PPT 其他例句：

- **Il est japonais ?** / **Est-ce qu'il est japonais ?** / **Est-il japonais ?**
- **Ton ami va comment ?** / **Comment est-ce que ton ami va ?** / **Comment va ton ami ?**

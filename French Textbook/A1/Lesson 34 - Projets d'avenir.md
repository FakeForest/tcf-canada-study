# Lesson 34 - Projets d'avenir

> [!info] 复习重点
> 未来计划：在电话里祝贺朋友、谈假期、工作和大学安排。把 **现在时 + 未来时间、最近将来时、简单将来时** 放在同一段对话里理解。

## 课文

### Justine 打电话给 Sophie

| 法语 | 中文 |
|---|---|
| **Allô !** | 喂！ |
| **Bonjour madame, c'est Justine.** | 您好，女士，我是 Justine。 |
| **Est-ce que Sophie est là ?** | Sophie 在吗？ |
| **Je peux lui parler ?** | 我可以和她说话吗？ |
| **Oui, bien sûr… Sophie, c'est Justine !…** | 当然……Sophie，是 Justine！…… |
| **Elle arrive tout de suite !** | 她马上就来！ |
| **Allô ! Justine ?** | 喂！Justine？ |
| **Salut Sophie !** | 你好，Sophie！ |
| **Bravo pour ton bac !** | 祝贺你通过高中毕业会考！ |
| **Merci.** | 谢谢。 |
| **Toi aussi, félicitations !** | 你也是，祝贺你！ |
| **Alors ?** | 那么？ |
| **Qu'est-ce que tu vas faire ?** | 你接下来打算做什么？ |
| **Tu as des projets ?** | 你有什么计划吗？ |
| **Ah ! oui, bien sûr…** | 啊！当然有…… |
| **Je vais d'abord me reposer !** | 我要先休息一下！ |
| **Je pars demain en vacances au Maroc…** | 我明天出发去摩洛哥度假…… |
| **Deux semaines.** | 两个星期。 |
| **Au Maroc !** | 去摩洛哥！ |
| **Ben, ce n'est pas comme ici !** | 嗯，那可不像这里！ |
| **Là, tu es sûre qu'il fera beau !…** | 在那儿，你可以肯定会是好天气！…… |
| **Et après ?** | 然后呢？ |
| **Après ?** | 然后？ |
| **Ben… j'essaierai de trouver un travail.** | 嗯……我会试着找份工作。 |
| **Ce n'est pas facile !** | 这可不容易！ |

| **Mon frère ouvre une crêperie dans un ou deux mois…** | 我哥哥一两个月后要开一家可丽饼店…… |
| **Enfin, je ne sais pas.** | 嗯，我也不知道。 |
| **On verra…** | 到时候再看吧…… |
| **Et toi ?** | 你呢？ |

| **Enfin, pas tout de suite, quoi !** | 总之，不是马上去啦！ |

| **Bon, eh bien, d'accord.** | 嗯，那好吧。 |
| **On s'appelle, alors !** | 那我们电话联系！ |

## 单词

| 法语 | 形式 | 中文 / 批注 |
|---|---|---|
| allô | 感叹词 | 喂，打电话时使用。 |
| appeler qn / s'appeler | 动词 | 给某人打电话 / 相互通电话；后者在本课不是“名叫”。 |
| rappeler qn / se rappeler | 动词 | 再给某人打电话 / 再次相互通电话；按本课语境理解。 |

| bac | n.m. | **baccalauréat** 的简称，高中毕业会考及文凭。 |

| Corse | n.f. | 科西嘉岛；**en Corse**。 |
| Maroc | n.m. | 摩洛哥；**au Maroc**。 |

### 第九单元补充：实用表达

| 课件表达 | 中文 / 联动 |
|---|---|
| **à l'avenir = dans le futur** | 在将来。 |
| **métro, boulot, dodo** | 地铁、工作、睡觉，概括日复一日的生活；教材旁也有这三个词的手写记忆。 |
| **On se connaît depuis longtemps.** | 我们认识很久了；现在时描述持续到现在的情况。 |
| **À bientôt !** | 回头见 / 不久后见；手写提示 **see u soon**。 |
| **À tout à l'heure !** | 待会儿见；手写提示“等会见，晚点见”。 |
| **À tout de suite !** | 马上见。 |
| **Elle arrive tout de suite.** | 她马上就来。 |
| **Ouvrir la fenêtre.** | 打开窗户。 |
| **Je vois. / On verra.** | 我明白了。/ 到时再看吧。 |

|---|---|
| je / tu / il, elle | essaie / essaies / essaie |
| nous / vous / ils, elles | essayons / essayez / essaient |

## 语法

### 1. 三种形式都可以谈将来

| 形式 | 课文例句 | 中文 / 观察点 |
|---|---|---|
| 现在时 + 未来时间 | **Je pars demain en vacances au Maroc.** | 我明天去摩洛哥度假；**demain** 明确未来时间。 |
| 现在时 + 未来时间 | **Mon frère ouvre une crêperie dans un ou deux mois.** | 我哥哥一两个月后开店。 |
| 最近将来时 | **Je vais d'abord me reposer.** | 我要先休息；**aller 现在时 + 不定式**。 |
| 最近将来时 | **Je vais donner des cours de tennis.** | 我要教网球。 |
| 简单将来时 | **J'essaierai de trouver un travail.** | 我将尝试找工作。 |
| 简单将来时 | **Je serai à la maison.** | 我到时会在家。 |

教材说明：现在时表达未来常有时间状语，口语中很常见。不要只看到现在时就译成“正在”；结合 **demain / la semaine prochaine / dans… / en octobre** 理解。

> 来源：[[taxi_1学生用书9.23.pdf#page=182|教材第 182 页：有关将来的表达]]。联动：[[Lesson 22 - Petites annonces#语法|第 22 课：最近将来时]]、[[Lesson 33 - Beau fixe#语法|第 33 课：简单将来时]]。

### 2. 第九单元补充：第一组动词的将来时词干变化

| 动词 | 课件例句 | 中文 / 拼写 |
|---|---|---|
| se lever | **Je me lèverai à 10 heures demain matin.** | 明早我十点起床；**lev- → lèv-**，自反代词仍在动词前。 |
| acheter | **Tu achèteras un grand appartement.** | 你将买一套大公寓；**achet- → achèt-**。 |
| appeler | **Je t'appellerai ce soir.** | 今晚我会给你打电话；**appeller-** 中有两个 **l**。 |
| essayer | **Nous essaierons de gagner de l'argent.** | 我们会努力挣钱；本课采用 **essaier-**。 |

这些例子的词尾仍是 **-ai, -as, -a, -ons, -ez, -ont**，改变的是词干的拼写。不要把课件标题下的几类拼写变化混成同一条规则。

> 来源：[[你好法语A1第九单元.pdf#page=16|课件第 16 页：简单将来时拼写变化]]。

### 3. 动词后接什么：直接宾语、`à`、`de`

| 搭配 | 例句 | 中文 |
|---|---|---|
| **appeler qn = téléphoner à qn** | **Je peux lui parler ?** | 打电话的两个动词宾语结构不同；课文这句 **lui** 来自 **parler à Sophie**。 |
| **essayer de + 不定式** | **J'essaierai de trouver un travail.** | 我会尝试找工作。 |
| **commencer à + 不定式** | **Les profs commencent à travailler à 7 h 30 tous les matins.** | 老师们每天早上七点半开始工作。 |
| **commencer + 名词** | **Les profs commencent le cours à 7 h 30 tous les matins.** | 老师们每天早上七点半开始上课。 |
| **arrêter de + 不定式** | **arrêter de faire qch** | 停止做某事，与 **commencer à** 对照。 |
| **donner des cours à qn** | **Il donne des cours aux étudiants de la première année.** | 他给一年级大学生上课。 |
| **suivre le cours de + 学科** | **suivre le cours de chinois** | 上中文课；与教师“授课”区分。 |

**cours de + 无冠词名词** 表示课程内容：**cours de tennis / de français / de musique**（网球课 / 法语课 / 音乐课）。

> 来源：[[taxi_1学生用书9.23.pdf#page=181|教材第 181 页：注释]]、[[你好法语A1第九单元.pdf#page=14|课件第 14 页：动词搭配]]、[[你好法语A1第九单元.pdf#page=15|第 15 页：教课与上课]]。

### 4. 电话里的固定说法

**C'est Justine.** 用于电话中说明身份；**On verra / Nous verrons** 表示“以后再说”。**Je t'embrasse** 在本课是熟人间结束通话时的亲切告别语。

> [!note] 第九单元听力页的使用
> [[你好法语A1第九单元.pdf#page=17|第 17 页]]是判断正误题，不能把其中的陈述直接背成课文事实：实际是 **Justine 给 Sophie 打电话**，Sophie 去 **Maroc（摩洛哥）**，Justine 不立刻度假是因为 **没有钱**。第 18 页是另一段听力的提问，未给出答案，本笔记不补造对话。

## 快速复习

> [!summary] 复习目标
> - 能用三种形式谈未来：**je pars demain / je vais partir / je partirai**。
> - 记住 **lèverai / achèteras / appellerai / essaierons** 的词干变化。
> - 分清 **commencer à / essayer de / arrêter de**。
> - 分清 **donner des cours**（教课）与 **suivre un cours**（上课）。
> - 会用 **à bientôt / à tout à l'heure / à tout de suite** 告别。

# Lesson 30 - Fait divers

> [!info] 复习重点
> 这一课的主题是“社会新闻 / 事故报道”。重点是把 **passé composé（复合过去时）** 和 **imparfait（未完成过去时）** 放在一起：前者讲发生了什么，后者描述当时背景、状态和习惯。

## 课文

### 广播新闻：A9 高速上的事故

| 法语 | 中文 |
|---|---|
| **Sud Radio... Il est midi. Les nouvelles du jour. Michel Rebourd.** | 这里是南方电台……中午 12 点。当日新闻。Michel Rebourd。 |
| **Bonjour. Un terrible accident vient de se passer sur l'autoroute A9, à côté de Nîmes, entre un camion et cinq voitures.** | 中午好。尼姆附近 A9 高速公路上刚刚发生了一起严重交通事故，一辆卡车和五辆小汽车相撞。 |
| **Il y a onze blessés.** | 有 11 人受伤。 |
| **Sur place, notre journaliste, Jérôme Duchamp...** | 我们的记者 Jérôme Duchamp 正在事故现场…… |
| **Oui, bonjour, Michel.** | 是的，中午好，Michel。 |
| **Alors voilà, je viens d'arriver sur l'autoroute A9, sur les lieux de l'accident.** | 是这样，我刚刚到达 A9 高速的事故现场。 |
| **Et j'ai devant moi Aline Besson.** | 站在我面前的是 Aline Besson 女士。 |
| **Quand l'accident est arrivé, Mme Besson traversait, à vélo, un pont au-dessus de l'autoroute.** | 事故发生时，Besson 女士正骑自行车经过高速公路上方的一座桥。 |
| **Et elle a tout vu.** | 她目睹了事情的全过程。 |
| **Alors, madame, qu'est-ce qui s'est passé exactement ?** | 那么，女士，当时究竟发生了什么？ |
| **Eh bien... Comme tous les matins, je traversais le pont.** | 嗯……像每天早上一样，我当时正从桥上经过。 |
| **Et alors... j'ai vu un camion se coucher sur la route.** | 然后……我看见一辆卡车侧翻在路上。 |
| **Des voitures suivaient le camion.** | 几辆小汽车跟在卡车后面。 |
| **Elles ont voulu s'arrêter mais elles roulaient trop vite, je pense.** | 它们想停下来，但我觉得车速太快了。 |
| **Et, en plus, il venait de pleuvoir, la route était glissante.** | 而且，刚刚下过雨，路面很滑。 |
| **Une première voiture a heurté le camion, et puis une deuxième, une troisième...** | 第一辆车撞上了卡车，然后第二辆、第三辆…… |
| **J'étais terrifiée. Vraiment !** | 我吓坏了。真的！ |

### 学会说

| 交际功能 | 法语 | 中文 |
|---|---|---|
| 讲述过去发生的事件 | **J'ai vu un camion se coucher sur la route.** | 我看见一辆卡车侧翻在路上。 |
| 描述动作发生时的背景 | **Quand l'accident est arrivé, la route était glissante.** | 事故发生时，路面很滑。 |
| 描述过去的状态 | **J'étais terrifiée.** | 我当时吓坏了。 |

## 语法

### 1. 未完成过去时的用法

**未完成过去时**常用来描述过去某个时段里的背景、状态、环境、外貌、心理活动或习惯。

| 用法 | 法语 | 中文 |
|---|---|---|
| 描述环境 | **La route était très glissante.** | 路面当时很滑。 |
| 描述天气 / 背景 | **Il faisait très froid.** | 当时天气很冷。 |
| 描述正在进行的状态 | **Le camion roulait trop vite.** | 卡车当时开得太快。 |
| 描述心理状态 | **J'étais terrifiée.** | 我当时吓坏了。 |
| 描述习惯 | **Avant, je prenais un café tous les matins.** | 以前我每天早上都喝一杯咖啡。 |
| 描述童年习惯 | **Quand j'étais petit, je me levais toujours très tôt.** | 我小时候总是起得很早。 |

### 2. 复合过去时 vs 未完成过去时

| 时态 | 核心作用 | 例子 |
|---|---|---|
| **passé composé** | 讲“发生了什么”；动作完成，时间界限比较明确 | **J'ai vu un camion.** |
| **imparfait** | 描述当时背景、状态、环境或习惯 | **Je traversais le pont.** |

两个时态经常搭配使用：

| 法语 | 中文 |
|---|---|
| **Elle traversait le pont quand l'accident est arrivé.** | 事故发生时，她正经过那座桥。 |
| **Il a pris un parapluie parce qu'il pleuvait.** | 因为当时在下雨，他拿了一把伞。 |
| **Elle avait 20 ans quand elle s'est mariée avec Pierre.** | 她和 Pierre 结婚时 20 岁。 |

### 3. `venir de + infinitif` 在过去背景中

在现在时里，**venir de + 动词不定式** 表示“刚刚”。如果故事已经在过去时间里，可以把 **venir** 放到未完成过去时：

| 法语 | 中文 |
|---|---|
| **Il vient de pleuvoir.** | 刚刚下过雨。 |
| **Il venait de pleuvoir.** | 当时刚下过雨。 |
| **Je viens d'arriver sur les lieux de l'accident.** | 我刚到事故现场。 |

### 4. `qu'est-ce qui` 问“什么东西 / 什么事”作主语

**qu'est-ce qui** 用来问“什么东西 / 什么事”作主语。

| 法语 | 中文 |
|---|---|
| **Qu'est-ce qui s'est passé exactement ?** | 究竟发生了什么？ |
| **Qu'est-ce qui fait ce bruit ?** | 是什么发出这个声音？ |
| **Qu'est-ce qui vous est arrivé ?** | 您发生什么事了？ |

> [!tip] 人和事要分开
> 问“谁”作主语时用 **qui**；问“什么事 / 什么东西”作主语时用 **qu'est-ce qui**。

### 第八单元补充：从“发生什么”到“当时怎样”

| 课件表达 | 中文 | 对比点 |
|---|---|---|
| **Qu'est-ce qui se passe ?** | 发生什么事了 / 正在发生什么？ | 现在的情况。 |
| **Qu'est-ce qui s'est passé ?** | 发生过什么事？ | 过去发生的事件。 |
| **Un accident est arrivé.** | 发生了一起事故。 | **arriver** 可表示“发生”。 |
| **Un accident m'est arrivé.** | 我遭遇了一起事故。 | **m'** 表示事故发生在“我”身上。 |
| **Il pleut. / Il a plu. / Il pleuvait.** | 在下雨。/ 下过雨了。/ 当时在下雨。 | 现在时 / 复合过去时 / 未完成过去时。 |
| **Mon fils suit le cours d'anglais maintenant.** | 我儿子现在在上英语课。 | **suivre** 除了“跟随”，还可表示“上课”。 |

课件用 **Avant, j'allais à l'école à vélo avec mon copain tous les jours.**（以前我每天和朋友骑车上学）说明过去习惯；用 **Quand j'étais petit, il y avait une gare devant chez moi.**（我小时候，我家前面有一个火车站）说明过去状态。先判断叙述作用，再选择时态。

## 快速复习

> [!summary] 复习目标
> - 会用 **passé composé** 讲事故里发生的动作：**j'ai vu**, **a heurté**, **a voulu s'arrêter**。
> - 会用 **imparfait** 描述事故背景：**je traversais**, **elles roulaient**, **la route était glissante**。
> - 会说“刚刚发生”：**vient de se passer**, **venait de pleuvoir**。
> - 会理解新闻报道里的 **sur place**, **sur les lieux de l'accident**, **fait divers**。

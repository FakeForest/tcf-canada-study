# Lesson 21 - C'est interdit !

> [!info] 复习重点
> 这一课进入第六单元，主题是“允许、禁止、拒绝”。语法重点是 **pouvoir**、**il est interdit de + 动词不定式**，以及间接宾语人称代词 **me, te, lui, nous, vous, leur** 的位置。

## 课文

### 对话 1：餐馆里禁止吸烟

| 法语 | 中文 |
|---|---|
| **Excusez-moi, madame, il est interdit de fumer dans le restaurant.** | 打扰一下，女士，餐馆里禁止吸烟。 |
| **Où est-ce que je peux fumer, alors ?** | 那我可以在哪里吸烟呢？ |
| **Vous pouvez fumer sur la terrasse.** | 您可以在露台吸烟。 |
| **Sur la terrasse ? Alors, ça ! Non merci !** | 在露台？这可不行！不用了，谢谢！ |
| **Madame, s'il vous plaît ! Ne fumez pas ici !** | 女士，拜托！请不要在这里吸烟！ |

### 对话 2：不能带狗进房间

| 法语 | 中文 |
|---|---|
| **Je voudrais une chambre, s'il vous plaît.** | 我想要一间房，谢谢。 |
| **Pour une personne.** | 一个人住。 |
| **Pour une personne... D'accord.** | 一个人……好的。 |
| **Donnez-moi votre passeport, s'il vous plaît.** | 请把您的护照给我。 |
| **Ah ! Vous avez un chien ?** | 啊！您有一只狗吗？ |
| **Oui.** | 是的。 |
| **Je suis désolée, monsieur, mais vous ne pouvez pas prendre votre chien avec vous dans la chambre.** | 很抱歉，先生，您不能把狗带进房间。 |
| **Mais comment ça ?!** | 这怎么回事？！ |

### 对话 3：飞机上不能打电话

| 法语 | 中文 |
|---|---|
| **Pardon, madame, vous ne pouvez pas utiliser votre portable.** | 不好意思，女士，您不能使用手机。 |
| **Comment ça, je ne peux pas !** | 什么叫我不能！ |
| **Mais je téléphone à mon fils !** | 可是我正在给我儿子打电话！ |
| **C'est très important !** | 这很重要！ |
| **Non madame, je suis désolée.** | 不行，女士，很抱歉。 |
| **Ce n'est pas possible.** | 这是不可以的。 |
| **On ne peut pas téléphoner dans l'avion.** | 飞机上不能打电话。 |
| **Téléphonez-lui à l'aéroport, à l'arrivée.** | 到达机场后给他打电话吧。 |

### 学会说：请求、允许、拒绝和表达禁令

| 交际功能 | 常用表达 | 中文 |
|---|---|---|
| 请求许可 | **Où est-ce que je peux fumer ?** | 我可以在哪里吸烟？ |
| 给予许可 | **Vous pouvez fumer sur la terrasse.** | 您可以在露台吸烟。 |
| 拒绝许可 | **Vous ne pouvez pas prendre votre chien.** | 您不能带您的狗。 |
| 表达禁令 | **Il est interdit de fumer.** | 禁止吸烟。 |
| 表达禁令 | **On ne peut pas téléphoner dans l'avion.** | 飞机上不能打电话。 |
| 表达禁令 | **Ce n'est pas possible.** | 这是不可以的。 |
| 表达禁令 | **Ne fumez pas !** | 不要吸烟！ |

### `pouvoir` 变位

| pouvoir |
|---|
| je peux |
| tu peux |
| il/elle peut |
| nous pouvons |
| vous pouvez |
| ils/elles peuvent |
| p.p. **pu** |

> [!attention] 倒装提醒
> 主谓倒装时要用 **puis-je**，不能说 **peux-je**。

### 课本注释

| 表达 | 说明 |
|---|---|
| **C'est interdit !** | 一个简单判断句，表示某件事在当前语境下被禁止。 |
| **Excusez-moi.** | 命令式，对“您/你们”发出礼貌请求；**moi** 是直接宾语人称代词。 |
| **il est interdit de + 动词不定式** | 表示“禁止做某事”。这里的 **il** 是中性代词，不指具体的人。 |

## 语法

### 1. `il est interdit de + 动词不定式`

这个结构用来表达一般性禁令。

| 法语 | 中文 |
|---|---|
| **Il est interdit de fumer dans la classe.** | 教室里禁止吸烟。 |
| **Il est interdit de téléphoner dans l'avion.** | 飞机上禁止打电话。 |

也可以用下面这些表达说“不可以”：

| 法语 | 中文 |
|---|---|
| **Ce n'est pas possible.** | 这不可能 / 不可以。 |
| **On ne peut pas téléphoner dans l'avion.** | 飞机上不能打电话。 |
| **Ne fumez pas ici !** | 请不要在这里吸烟！ |

### 2. 间接宾语人称代词

间接宾语人称代词用来代替由 **à** 或 **pour** 引出的间接宾语。

| 中文 | 间接宾语代词 | 中文 | 间接宾语代词 |
|---|---|---|---|
| 我 | me / m' | 我们 | nous |
| 你 | te / t' | 你们 / 您 | vous |
| 他 / 她 | lui | 他们 / 她们 | leur |

### 3. 间接宾语代词的位置

| 结构 | 位置 | 例句 |
|---|---|---|
| 肯定句 | 放在相关动词前 | **Nous disons bonjour à Sophie. -> Nous lui disons bonjour.** |
| 否定句 | **ne** 放在代词前，**pas** 放在动词后 | **Il ne parle pas à ses parents. -> Il ne leur parle pas.** |
| 否定命令式 | **ne + 代词 + 动词 + pas** | **Ne lui parle pas de ça !** |
| 有不定式 | 放在不定式前 | **Peux-tu me donner une assiette ?** |
| 肯定命令式 | 放在动词后，用连字符连接 | **Raconte-moi cette histoire.** / **Téléphonez-lui.** |
| 复合过去时肯定句 | 放在助动词前 | **Paul a téléphoné à sa copine. -> Paul lui a téléphoné.** |
| 复合过去时否定句 | **ne** 放在代词前，**pas** 放在助动词后 | **Je n'ai pas acheté ce livre pour mes enfants. -> Je ne leur ai pas acheté ce livre.** |

### 4. 饮食限制场景

医生建议饮食时，可以用 **pouvoir / ne pas pouvoir** 表示“可以吃 / 不可以吃”。

| 可以 | 不可以 |
|---|---|
| **le poisson** | **le beurre** |
| **les pâtes** | **les pommes de terre** |
| **les légumes** | **le chocolat** |
| **les fruits** | **l'alcool** |

## 快速复习

> [!summary] 复习目标
> - 会用 **pouvoir** 表达“能 / 可以”：**je peux**, **vous pouvez**, **ils peuvent**。
> - 会用 **il est interdit de + 动词不定式** 表达禁令。
> - 会用 **ce n'est pas possible** 和 **on ne peut pas...** 拒绝许可。
> - 会把间接宾语代词放在正确位置：**je lui téléphone**, **ne leur parle pas**, **Paul lui a téléphoné**。

### 第六单元补充：同一个宾语在八种句式里的位置

从 **Tu téléphones à Paul.**（你给 Paul 打电话）出发，**à Paul → lui**。**lui** 既可指“他”，也可指“她”；**leur** 指“他们 / 她们”，不加 **s**。

| 句式 | 法语 | 中文 |
|---|---|---|
| 现在时肯定 | **Tu lui téléphones.** | 你给他打电话。 |
| 现在时否定 | **Tu ne lui téléphones pas.** | 你不给他打电话。 |
| 有不定式 | **Tu peux lui téléphoner.** | 你可以给他打电话。 |
| 有不定式的否定 | **Tu ne peux pas lui téléphoner.** | 你不能给他打电话。 |
| 复合过去时 | **Tu lui as téléphoné.** | 你给他打过电话了。 |
| 复合过去时否定 | **Tu ne lui as pas téléphoné.** | 你没给他打电话。 |
| 肯定命令式 | **Téléphone-lui !** | 给他打电话！ |
| 否定命令式 | **Ne lui téléphone pas.** | 不要给他打电话。 |

**me / te** 在元音或哑音 h 前省音为 **m' / t'**；在本课的肯定命令式里改为 **moi / toi**，用连字符与动词连接，如 **Donnez-moi votre passeport.**

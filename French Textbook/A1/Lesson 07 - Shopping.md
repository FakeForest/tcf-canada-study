# Lesson 7 - Shopping

> [!info] 复习重点
> **课文 + 单词 + 语法**。这一课通过购物对话复习衣服、颜色、尺码、价格和喜好表达。

## 课文

### 对话：买衣服

| 法语 | 中文 |
|---|---|
| **Bonjour, mesdames, qu'est-ce que vous cherchez ?** | 您好，女士们，您们在找什么？ |
| **Des vêtements pour ma fille et mon fils.** | 给我女儿和儿子买衣服。 |
| **Quel âge ont-ils ?** | 他们多大？ |
| **Ma fille a 16 ans et mon fils 14.** | 我女儿 16 岁，我儿子 14 岁。 |
| **Pour les filles, c'est sur les étagères à gauche et pour les garçons, à droite.** | 女孩的在左边架子上，男孩的在右边。 |

### 对话：看颜色和尺码

| 法语 | 中文 |
|---|---|
| **Comment est-ce que tu trouves ce pantalon ?** | 你觉得这条裤子怎么样？ |
| **J'aime bien ce type de pantalon, c'est très joli !** | 我很喜欢这种裤子，很漂亮！ |
| **Vous avez quelles couleurs, s'il vous plaît ?** | 请问您们有什么颜色？ |
| **Ce pantalon ? Il y a bleu, gris ou noir.** | 这条裤子吗？有蓝色、灰色或黑色。 |
| **Il coûte combien ?** | 它多少钱？ |
| **59 euros.** | 59 欧元。 |
| **Ce n'est pas très cher !** | 不是很贵！ |
| **Hum, hum. Pas très cher...** | 嗯，嗯。不太贵…… |
| **Vous avez le gris en taille 38 ?** | 灰色的有 38 码吗？ |
| **Oui.** | 有。 |
| **Cette robe verte, tu aimes ?** | 这条绿色连衣裙，你喜欢吗？ |
| **Oh, non ! Pas du tout !** | 哦，不！一点也不！ |
| **Ah bon ! Et ce pull ? Il est joli, non ?** | 啊，是吗！那这件套头衫呢？它很漂亮，对吧？ |
| **Oui, le bleu et blanc, j'aime bien.** | 是的，蓝白色那件，我挺喜欢。 |

### 对话：结账

| 法语 | 中文 |
|---|---|
| **Combien ça coûte ?** | 这多少钱？ |
| **35 euros.** | 35 欧元。 |
| **Bon, alors... Ce pull et ce pantalon, ça fait combien, s'il vous plaît ?** | 好，那么……这件套头衫和这条裤子一共多少钱？ |
| **35 et 59... ça fait 94 euros, madame.** | 35 加 59……一共 94 欧元，女士。 |
| **Voilà !** | 给您！ |

## 语法

### 1. `quel` 的复数形式

| 阳性复数 | 阴性复数 |
|---|---|
| quels livres | quelles filles |

> **Quels vêtements est-ce qu'il porte ?**  
> **Vous avez quelles couleurs ?**  
> **Quels sont vos romans ?**

### 2. `comment` 和 `combien`

| 问法 | 例句 |
|---|---|
| `comment` = manner / state | **Comment est-ce que tu trouves ce pantalon ?** |
| `comment` = “how is” | **Elle est comment, ton amie Christine ?** |
| `combien` = 数量 / 价格 | **Elle coûte combien, cette robe ?** |
| `combien coûte...` | **Combien coûte-t-il, ce pull ?** |

> 来源: [[你好法语A1第二单元.pdf#page=27|你好法语A1第二单元.pdf - 第 27 页和第 30-31 页]]

PPT 给出三种询问价格的语序：

| 语体 | 结构 | 例句 |
|---|---|---|
| 书面 | 疑问词 + 主谓倒装 | **Combien coûte ton manteau brun ?** |
| 书面 / 口语 | 疑问词 + **est-ce que** + 陈述语序 | **Combien est-ce que ton manteau brun coûte ?** |
| 口语 | 陈述语序 + 疑问词 | **Ton manteau brun coûte combien ?** |

询问数量时，用 **combien de + 不带冠词的名词**，整体作为一个单位：

- **Il y a combien de personnes dans ta famille ?**
- **Combien de tables y a-t-il dans la classe ?**
- **Combien de livres est-ce que tu as ?**

### 3. 指示形容词

| | 阳性 | 阴性 |
|---|---|---|
| singular | ce garçon / cet étudiant | cette fille |
| plural | ces garçons / ces étudiants | ces filles |

- 在元音或哑音 `h` 前，阳性单数用 **cet**：**cet objet**, **cet hôtel**。
- **Cette voiture est très chère.**
- **Je n'aime pas ces deux livres.**

> 来源: [[你好法语A1第二单元.pdf#page=29|你好法语A1第二单元.pdf - 第 29 页]]

PPT 把指示形容词和前面学过的限定词放在一起比较：定冠词、不定冠词、主有形容词、指示形容词、疑问形容词都放在名词前。

### 4. `faire`

| 主语 | 形式 |
|---|---|
| je / tu / il-elle | je fais / tu fais / il-elle fait |
| nous / vous / ils-elles | nous faisons / vous faites / ils-elles font |

### 5. `quel` 和 `que` 的区别

> 来源: [[你好法语A1第二单元.pdf#page=32|你好法语A1第二单元.pdf - 第 32 页]]

| 疑问词 | 作用 | 例句 |
|---|---|---|
| **quel(le)(s)** | 疑问形容词，修饰后面的名词 | **Quelles fleurs aimes-tu ?** |
| **quel + être** | 询问“是什么/哪一个”，要做性数配合 | **Quelle est ta profession ?** |
| **que / qu'est-ce que** | 疑问代词，在句中作宾语 | **Qu'est-ce que tu aimes ?** |

## 课文

### 对话 1

| 法语 | 中文 |
|---|---|
| **Bonjour, monsieur.** | 您好，先生。 |
| **Vous vous appelez... ?** | 您叫什么名字？ |
| **Doucet. Yves Doucet.** | Doucet。Yves Doucet。 |
| **Et voici ma femme, Alice.** | 这是我的妻子 Alice。 |
| **Bonjour, madame.** | 您好，女士。 |

### 对话 2

| 法语 | 中文 |
|---|---|
| **Bonjour.** | 您好。 |
| **Je suis Alice Doucet.** | 我是 Alice Doucet。 |
| **Vous êtes madame Falco ?** | 您是 Falco 女士吗？ |
| **Bonjour. Oui, je m'appelle Nicole Falco.** | 您好。是的，我叫 Nicole Falco。 |
| **Aldo, mon mari.** | Aldo，我的丈夫。 |
| **Arnaud ?** | Arnaud？ |
| **Non. Aldo.** | 不是，Aldo。 |
| **Il s'appelle Aldo.** | 他叫 Aldo。 |

### 对话 3

| 法语 | 中文 |
|---|---|
| **Qui est-ce ?** | 这是谁？ |
| **C'est Aldo.** | 这是 Aldo。 |
| **Aldo Falco.** | Aldo Falco。 |
| **Aldo ? Il est italien ?** | Aldo？他是意大利人吗？ |
| **Oui, et elle, c'est Nicole, elle est française.** | 是的。她呢，这是 Nicole，她是法国人。 |

### 对话 4

| 法语 | 中文 |
|---|---|
| **Tu t'appelles Giacomo !** | 你叫 Giacomo！ |
| **Tu es italien ?** | 你是意大利人吗？ |
| **Oui, oui. Je suis italien.** | 是的，是的。我是意大利人。 |

> [!note] 课文页手写提示
> - **Bienvenue !** (`well`, `welcome`)
> - **monsieur** 旁边有手写发音提示。
> - **vous vous appelez** 旁边有手写发音标记。
> - **femme** 旁边有手写提示。
> - **française** 词尾附近有一个小的手写发音提示。
> - **mon / ma / mes** 被标注为 `my`：**mon** = 阳性单数，**ma** = 阴性单数，**mes** = 复数。

## 语法

### 1. `vous` 和 `tu`

- **vous** = 你们 / 您
- **tu** = 你
- 初次见面或保持礼貌距离时用 **vous**，常和 **monsieur** / **madame** 搭配。
- Family, friends, colleagues, classmates: use **tu**.

> Bonjour, monsieur. Vous êtes italien ?  
> Bonjour, Alice. Tu es française ?

### 2. 主语人称代词

`je` · `tu` · `il` · `elle` · `nous` · `vous` · `ils` · `elles`

### 3. `s’appeler`：叫作 / 名字是

| 主语 | 形式 |
|---|---|
| je | je m’appelle |
| tu | tu t’appelles |
| il / elle | il / elle s’appelle |
| vous | vous vous appelez |

### PPT 句型补充

> 来源: [[你好法语A1第一单元.pdf#page=2|你好法语A1第一单元.pdf - 第 2 页]]

PPT 给出几种人称下询问姓名的句型：

| 问句 | 用法 |
|---|---|
| **Comment tu t'appelles ?** | 非正式：你叫什么？ |
| **Tu t'appelles ... ?** | 非正式确认：你叫……吗？ |
| **Comment vous vous appelez ?** | 正式/复数：您/你们叫什么？ |
| **Vous vous appelez ... ?** | 正式/复数确认：您/你们叫……吗？ |
| **Comment il / elle s'appelle ?** | 询问另一个人的名字 |

用来识别人物时，PPT 也把 **Qui est-ce ? C'est...** 和 **Voici...** 放在同一个介绍/指出某人的功能里。

### 4. 第一组 `-er` 动词

法语动词形式会随主语、时态、语式变化。第一组动词通常以 `-er` 结尾。

To form the present tense, remove `-er` and add:

| 主语 | 词尾 | `habiter` 示例 |
|---|---:|---|
| je | `-e` | j’habite |
| tu | `-es` | tu habites |
| il / elle | `-e` | il / elle habite |
| nous | `-ons` | nous habitons |
| vous | `-ez` | vous habitez |
| ils / elles | `-ent` | ils / elles habitent |

> [!important] 来源中标出的不发音字母
> - **tu habites** 词尾 `s` 被划掉，表示不发音。
> - **ils / elles habitent** 词尾 `nt` 被划掉，表示不发音。

### 5. 省音

在元音或哑音 `h` 前，以元音结尾的小词常会省音，用撇号连接：

- `je habite` → **j’habite**
- `ce est` → **c’est**
- `la étudiante` → **l’étudiante**

### 6. `être`：是 / 在

| 主语 | 形式 |
|---|---|
| je | je suis |
| tu | tu es |
| il / elle | il / elle est |
| nous | nous sommes |
| vous | vous êtes |
| ils / elles | ils / elles sont |

### 7. 阴阳性

> C’est Yves, il est français.  
> C’est Alice, elle est française.

- 名词、代词、形容词和冠词都有语法性别。
- Vocabulary entries use `n.m.` for masculine nouns and `n.f.` for feminine nouns.
- 例句中代词、形容词、冠词都要和名词性别配合。
- 小写 **française** 是国籍形容词。
- 大写 **Française** 是名词：`C’est une Française.`

### 8. `Qui est-ce ?`：这是谁？

> Qui est-ce ? / C’est qui ?  
> C’est Nicole.

回答多个人是谁时，用 **être** 的第三人称复数：

> Ce sont Aldo et Giacomo.

# Lesson 6 - Portrait-robot

> [!info] 复习重点
> **课文 + 单词 + 语法**. 这一课describes people, clothes, colours, and possession.

## 课文

### 对话：模拟画像

| 法语 | 中文 |
|---|---|
| **Alors... Ils sont grands ? petits ?** | 那么……他们个子高？还是矮？ |
| **Il y a un homme, grand et... blond.** | 有一个男人，个子高，而且……金发。 |
| **Oui, c'est ça, il est blond.** | 对，就是这样，他是金发。 |
| **L'autre homme, il est petit et brun.** | 另一个男人个子矮，是深色头发。 |
| **D'accord !** | 好的！ |
| **Est-ce qu'ils ont des lunettes ?** | 他们戴眼镜吗？ |
| **Non, non, ils n'ont pas de lunettes.** | 不，不，他们没有戴眼镜。 |
| **Et leurs vêtements ?** | 那他们的衣服呢？ |
| **L'homme blond porte un tee-shirt blanc et un pantalon noir...** | 金发男人穿一件白色 T 恤和一条黑色裤子…… |
| **Non, bleu, un pantalon bleu.** | 不，是蓝色，一条蓝色裤子。 |
| **C'est un jean.** | 这是一条牛仔裤。 |
| **L'homme brun, lui, il a un blouson.** | 深色头发的男人呢，他有一件夹克。 |
| **De quelle couleur ?** | 什么颜色？ |
| **La couleur de son blouson... noir...** | 他的夹克颜色……黑色…… |
| **Non, ce n'est pas noir... rouge... oui, rouge.** | 不，不是黑色……红色……对，红色。 |
| **Autre chose ?** (`Any thing else?`) | 还有别的吗？ |
| **Oui, sa chemise est verte.** | 有，他的衬衫是绿色的。 |
| **Et ses chaussures ?** | 他的鞋呢？ |
| **Ah ! ce sont des baskets.** | 啊！是运动鞋。 |

### 实用句型

| 法语 | 中文 |
|---|---|
| **À qui est le tee-shirt rouge ?** | 这件红色 T 恤是谁的？ |
| **Il est à lui.** | 它是他的。 |
| **La couleur de son blouson ? Rouge.** | 他夹克的颜色？红色。 |
| **Elle a une robe verte.** | 她有一条绿色连衣裙。 |

## 语法

### 1. 重读人称代词

| 人称 | 形式 |
|---|---|
| 我 / 你 | moi / toi |
| 他 / 她 | lui / elle |
| 我们 / 您；你们 | nous / vous |

- **Tu viens avec moi ?**
- **Lui, il s'appelle Paul.**
- **La fille blonde, elle, a une robe bleue.**
- **Sophie ? C'est toi ?**

> 来源: [[你好法语A1第二单元.pdf#page=17|你好法语A1第二单元.pdf - 第 17 页]]

PPT 完整形式和用法：

| 主语人称代词 | 重读人称代词 |
|---|---|
| je | moi |
| tu | toi |
| il | lui |
| elle | elle |
| nous | nous |
| vous | vous |
| ils | eux |
| elles | elles |

| 用法 | 例句 |
|---|---|
| short answer / elliptical phrase | **Je vais bien, et toi ?** |
| apposition to emphasize subject | **Moi, je m'appelle Amélie.** |
| 介词后 | **Mon mari habite à Lyon avec moi.** |
| 在 **c'est** 后作补语 | **Le livre, c'est à qui ? C'est à lui.** |
| identification | **Madame Dupont, c'est vous ?** |

### 2. 主有形容词 (复数拥有者)

| 拥有者 | 单数名词 | 复数名词 |
|---|---|---|
| 我们 | notre professeur / notre fille | nos professeurs / nos filles |
| 您；你们 | votre ami / votre amie | vos amis / vos amies |
| 他们；她们 | leur ami / leur tante | leurs amis / leurs tantes |

### 3. 形容词配合

| 阳性 | 阴性 |
|---|---|
| japonais | japonaise |
| italien | italienne |
| américain | américaine |
| familier | familière |
| neuf | neuve |
| cher | chère |
| heureux | heureuse |

形容词要和名词做阴阳性、单复数配合：**une robe verte**, **des chaussures noires**, **les cheveux blonds**。

### 4. 否定结构：`ne...pas`

> **Ce ne sont pas mes fleurs.**  
> **Je n'habite pas ici.**  
> **Non, ils n'ont pas de lunettes.**

> 来源: [[你好法语A1第二单元.pdf#page=19|你好法语A1第二单元.pdf - 第 19-20 页]]

基本否定结构：**ne ... pas** 包住变位动词。

| 肯定 | 否定 |
|---|---|
| **Je suis anglais.** | **Je ne suis pas anglais.** |
| **C'est une robe.** | **Ce n'est pas une robe.** |
| **Mes parents habitent en Italie.** | **Mes parents n'habitent pas en Italie.** |
| **Tu aimes le café ?** | **Non, je n'aime pas le café.** |

在元音或哑音 `h` 前，**ne** 省音为 **n'**。

如果直接宾语被完全否定，**un / une / des** 通常变成 **de**：

| 肯定问句 / 肯定句 | 否定句 |
|---|---|
| **Tu as une sœur ?** | **Je n'ai pas de sœur.** |
| **Il y a des fleurs sur la table.** | **Il n'y a pas de fleur sur la table.** |
| **Anne a un sac noir.** | **Anne n'a pas de sac noir.** |

PPT 总结条件：否定句 + 直接宾语 + 不定冠词/部分冠词时，冠词通常变 **de**。

### 5. PPT 语法补充：颜色和形容词配合

> 来源: [[你好法语A1第二单元.pdf#page=12|你好法语A1第二单元.pdf - 第 12 页和第 21-24 页]]

Colors can be adjectives or nouns:

| 用法 | 规则 | 例子 |
|---|---|---|
| 作形容词 | 与名词配合，通常放在名词后 | **une table verte**, **un chapeau rouge** |
| 作名词 | 阳性单数 | **J'aime le rouge, le blanc et le noir.** |
| 描述人 | 常指发色 | **Camille est blonde.** |

常见形容词阴性变化：

| 阳性 | 阴性 | Rule |
|---|---|---|
| vert | verte | add **-e** |
| rouge | rouge | already ends in **-e** |
| italien | italienne | **-ien → -ienne** |
| neuf | neuve | **-f → -ve** |
| heureux | heureuse | **-x → -se** |
| cher | chère | **-er → -ère** |

三个特殊形容词：

| 中文 | 阳性单数：辅音前 | 阳性单数：元音前 | 阴性单数 | 阳性复数 | 阴性复数 |
|---|---|---|---|---|---|
| beautiful | beau | bel | belle | beaux | belles |
| new | nouveau | nouvel | nouvelle | nouveaux | nouvelles |
| old | vieux | vieil | vieille | vieux | vieilles |

例句：

- **un beau chapeau** / **un bel homme** / **une belle femme**
- **un nouveau chapeau** / **un nouvel ami** / **une nouvelle amie**
- **un vieux chapeau** / **un vieil homme** / **une vieille femme**

复数形容词放在名词前时，**des** 通常变 **de**：

> **des belles filles → de belles filles**

PPT 还总结了配合（`accord`）：冠词、主有形容词、名词、形容词都要和核心名词的阴阳性、单复数配合。

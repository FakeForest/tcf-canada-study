# Lesson 26 - Quitter Paris

> [!info] 复习重点
> 这一课的主题是“离开巴黎 / 城市与乡下生活”。语法重点是 **parce que** 表达原因，**trop / assez** 表示程度或数量，**tout** 的形容词和代词用法，以及代词式动词的意义分类。

## 课文

### 离开巴黎

| 法语                                                                                                           | 中文                        |
| ------------------------------------------------------------------------------------------------------------ | ------------------------- |
| **Comment ! Céline et toi, vous quittez Paris ?**                                                            | 怎么！你和 Céline，你们要离开巴黎？     |
| **Eh oui, on a acheté une maison à la campagne, à côté d'Albi.**                                             | 是啊，我们在乡下买了一座房子，在 Albi 附近。 |

| **Elle aussi, elle préfère partir.**                                                                         | 她也宁愿离开巴黎。                 |
| **Vous avez peut-être raison...**                                                                            | 可能你们是对的吧……                |

### 学会说：询问和表达意见

| 交际功能 | 常用表达 | 中文 |
|---|---|---|
| 询问意见 | **Qu'est-ce qu'elle en pense ?** | 她对此怎么看？ |
| 表达意见 | **Je trouve ça pas mal du tout.** | 我觉得这挺好的。 |
| 表达不喜欢 | **Je n'aime pas ça.** | 我不喜欢这个。 |
| 表示同意 | **Je suis d'accord.** | 我同意。 |
| 表示对方有道理 | **Vous avez raison.** | 你们说得对。 |
| 表示异议 | **Qu'est-ce que tu t'imagines !** | 你想什么呢！ |
| 表示不理解 | **Je ne comprends pas !** | 我不明白！ |

## 语法

### 1. 用 `pourquoi` 提问，用 `parce que` 回答原因

| 法语 | 中文 |
|---|---|
| **Pourquoi est-ce que vous partez à la campagne ?** | 你们为什么要搬到乡下？ |
| **Parce que c'est trop bruyant à Paris.** | 因为巴黎太吵了。 |
| **Parce qu'à Paris, il y a trop de voitures.** | 因为巴黎车太多了。 |

### 2. `trop / assez`

**trop** 和 **assez** 可以修饰动词、形容词，也可以接 **de + 名词** 表示数量。

| 结构 | 法语 | 中文 |
|---|---|---|
| **trop + 形容词 / 动词** | **Cette rue est trop bruyante.** | 这条街太吵了。 |
| **trop + 形容词 / 动词** | **Tu travailles trop, tu vas te fatiguer.** | 你干太多了，会累着的。 |
| **assez + 形容词 / 动词** | **Ce manteau est assez chaud.** | 这件大衣挺暖和。 |
| **assez + 形容词 / 动词** | **Vous avez assez travaillé.** | 您干得够多了。 |
| **trop de + 名词** | **Il y a trop de monde à Beijing.** | 北京的人太多了。 |
| **pas trop de + 名词** | **Ne mange pas trop de viande !** | 别吃太多肉！ |
| **assez de + 名词** | **Il y a assez de choses à faire.** | 有相当多的事情要做。 |
| **pas assez de + 名词** | **Il n'a pas assez de temps libre pour voyager.** | 他没有足够的空闲时间去旅行。 |

> [!attention] 冠词提醒
> **beaucoup / un peu / peu / trop / assez + de + 名词** 中，名词前面不带冠词。

### 3. `tout`：泛指形容词和泛指代词

**tout** 作泛指形容词时，放在名词前，并和名词保持性、数一致。

| 形式 | 中文 | 例句 |
|---|---|---|
| tout | 单数阳性：“整个的” | **Tout le monde se connaît.** = 所有人都互相认识。 |
| toute | 单数阴性：“整个的” | **Toute sa famille habite là-bas.** = 他 / 她全家都住在那里。 |
| tous | 复数阳性：“所有的” | **Tous nos amis viennent ce soir.** = 我们所有的朋友今晚都来。 |
| toutes | 复数阴性：“所有的” | **Toutes les filles aiment ce film.** = 所有女孩都喜欢这部电影。 |

**tout** 作泛指代词时，表示“一切 / 所有的事物 / 所有的人”，在句中可以作主语、宾语、表语或同位语。

| 法语 | 中文 |
|---|---|
| **Tout va bien.** | 一切都很好。 |
| **Je mange tout.** | 我什么都吃。 |
| **Je les connais tous.** | 我认识他们所有的人。 |
| **Elles aiment toutes ce chanteur.** | 她们都喜欢这位歌手。 |

### 4. `gens` 的性

**gens** 是复数名词，阴阳属性比较特殊。

| 情况 | 用法 | 例子 |
|---|---|---|
| 形容词位于 **gens** 前 | **gens** 作阴性名词，形容词用阴性复数 | **les vieilles gens** = 老人们；**de petites gens** = 收入微薄者 |
| 形容词 / 代词 / 分词位于 **gens** 后，或作表语 | **gens** 作阳性名词 | **les gens sots** = 愚蠢的人们 |
| 后接由 **de** 引导、表示性质或职业的名词 | **gens** 作阳性名词 | **gens d'affaires** = 商界人士；**gens de lettres** = 文人、作家 |

### 5. `penser de`

**penser... de + 某个事件 / 事物** 表示“对某事 / 某物有……的看法”。

| 法语 | 中文 |
|---|---|
| **Qu'est-ce qu'elle en pense ?** | 她对这件事是怎么想的？ |
| **Que pensez-vous de cette solution ?** | 你们对这个解决办法有什么看法？ |
| **As-tu vu le dernier film de Luc Besson ? Qu'en penses-tu ?** | 你看了 Luc Besson 的新作吗？你觉得怎么样？ |

如果 **de** 后面的宾语指人，第二次出现时用 **de + 重读人称代词**：

| 法语 | 中文 |
|---|---|
| **Que penses-tu de ton patron ?** | 你觉得你老板怎么样？ |
| **Tu as vu la nouvelle directrice ? Que penses-tu d'elle ?** | 你见过新经理吗？你觉得她怎么样？ |

### 6. 代词式动词的意义分类

| 类型 | 说明 | 例句 |
|---|---|---|
| 自反意义 | 动作作用于主语自身 | **Il se lave tous les jours.** = 他每天都洗澡。 |
| 自反意义 | 动作直接宾语仍可出现 | **Il se lave les mains avant le repas.** = 他餐前洗手。 |
| 相互意义 | 多个主语互相做某事 | **Ils se regardent sans rien dire.** = 他们默不作声地看着对方。 |
| 相互意义 | 可包含各自的直接宾语 | **Ils se serrent la main et se disent bonjour.** = 他们相互握手问候。 |
| 被动意义 | 形式为代词式，意思接近被动 | **Les pommes se vendent bien aujourd'hui.** = 今天苹果卖得不错。 |
| 绝对意义 | 自反代词只是动词固定组成部分 | **Les oiseaux s'envolent.** = 鸟儿都飞走了。 |

### 第七单元补充：相同形式，不同意思

| 课件例句 | 中文 | 观察点 |
|---|---|---|
| **Elle se regarde dans le miroir.** | 她照镜子看自己。 | 自反：看的是自己。 |
| **Julie et Paul se marient.** | Julie 和 Paul 结婚。 | 相互关系；也可说 **Julie se marie avec Paul.** |
| **Ce vin se boit bien.** | 这种酒很好入口。 | 被动意义：酒是被喝的。 |
| **Pékin se trouve dans le nord de la Chine.** | 北京位于中国北部。 | **se trouver** 是“位于”的固定用法。 |
| **Je trouve mon sac sous le lit.** | 我在床底下找到我的包。 | **trouver**：找到。 |
| **Je trouve sa fille jolie.** | 我觉得他的 / 她的女儿很漂亮。 | **trouver + 宾语 + 形容词**：觉得……怎样。 |

**tout + 限定词 + 名词**：**tout le monde**（所有人）、**tous les jours**（每天）、**toute la journée**（一整天）、**toutes les filles**（所有女孩）。后两类要注意“整段时间”和“重复多次”的区别。

**Je les connais tous.** = 他们我全认识。**les** 已经是宾语，**tous** 强调“所有人”；**Elles aiment toutes Chanel.** = 她们全都喜欢香奈儿，**toutes** 则强调主语 **elles**。

课件把 **penser de** 的两种替换并列：**Qu'est-ce que tu penses de mon sac ? → Qu'est-ce que tu en penses ?**（你觉得我的包怎么样？）；**Que penses-tu de mon copain ? → Que penses-tu de lui ?**（你觉得我男朋友怎么样？）。

## 快速复习

> [!summary] 复习目标
> - 会用 **pourquoi / parce que** 问原因和说明理由。
> - 会区分 **trop bruyant**、**trop de voitures**、**pas assez d'espaces verts**。
> - 会用 **tout / toute / tous / toutes**。
> - 记住 **gens** 的性会随位置和结构变化。
> - 会问“你怎么看”：**Qu'est-ce que tu en penses ?**
> - 会说“你有道理”：**Tu as raison. / Vous avez raison.**

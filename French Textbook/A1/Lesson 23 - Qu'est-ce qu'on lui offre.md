# Lesson 23 - Qu'est-ce qu'on lui offre ?

> [!info] 复习重点
> 这一课的主题是“送礼建议”。语法重点是 **直接宾语人称代词 COD**，以及第二组规则 **-ir** 动词变位；动词重点是 **connaître, offrir, choisir**。

## 课文

### 我们送她什么呢？

| 法语 | 中文 |
|---|---|
| **Mais ! Qu'est-ce que vous faites ?** | 哎，你们在做什么呢？ |
| **On cherche une idée de cadeau pour Colette.** | 我们正在想送给 Colette 的礼物。 |
| **C'est son anniversaire ?** | 是她生日吗？ |
| **Elle quitte l'agence cette semaine. Elle part à la retraite.** | 她这周要离开公司，要退休了。 |
| **On lui offre un cadeau pour son départ.** | 我们给她送一份离别礼物。 |
| **On ne sait pas quoi acheter.** | 我们不知道买什么好。 |
| **Tu la connais bien, toi, Colette. Quels sont ses goûts ?** | 你很了解 Colette。她有什么喜好？ |
| **Qu'est-ce qu'elle aime ? Je ne sais pas, moi...** | 她喜欢什么？我也不知道啊…… |
| **Offrez-lui des fleurs...** | 送她花吧…… |
| **Ou pourquoi pas un CD de Pavarotti ? Elle l'adore !** | 或者为什么不送一张 Pavarotti 的 CD？她很喜欢他！ |
| **Ce n'est pas très original !** | 这不是很有创意！ |
| **Vous pouvez lui offrir un livre d'art sur la photo ou sur la peinture.** | 你们可以送她一本关于摄影或绘画艺术的书。 |
| **Le directeur lui achète un livre !** | 经理也给她买书！ |
| **Je suis désolé mais je n'ai pas d'autre idée...** | 很抱歉，我没有别的主意了…… |

### 学会说：提出、接受和拒绝建议

| 交际功能 | 常用表达 | 中文 |
|---|---|---|
| 给出建议 | **Offrez-lui des fleurs.** | 送她花吧。 |
| 给出建议 | **Pourquoi pas un CD ?** | 为什么不送一张 CD 呢？ |
| 给出建议 | **Vous pouvez offrir un livre d'art.** | 你们可以送一本艺术书。 |
| 接受建议 | **Oui. C'est une bonne idée.** | 好，这是个好主意。 |
| 拒绝建议 | **Ah ! mais non.** | 哎，不行。 |
| 拒绝建议 | **Ce n'est pas très original.** | 这不太有创意。 |
| 拒绝建议 | **Non, je ne peux pas.** | 不，我不可以。 |

## 语法

### 1. `mais` 的几种用法

| 用法 | 说明 | 例句 |
|---|---|---|
| 加强语气 | 相当于“当然，确实”，常用于强调 | **Mais oui, c'est vrai !** |
| 表示转折 | 相当于“可是，但是，然而” | **Oui, mais on ne sait pas quoi acheter.** |
| 表示惊讶 / 怀疑 / 愤慨 | 在感叹句或疑问句中承上启下 | **Mais pourquoi ?** / **Mais non !** |

### 2. `partir à la retraite / prendre sa retraite / être à la retraite`

| 表达 | 中文 | 重点 |
|---|---|---|
| **partir à la retraite** | 退休，离开岗位进入退休状态 | 强调“步入退休”这个动作 |
| **prendre sa retraite** | 退休 | 也强调退休动作 |
| **être à la retraite** | 处于退休状态 | 强调“已经退休”的状态 |

例句：

| 法语 | 中文 |
|---|---|
| **Elle va prendre sa retraite dans un mois.** | 她一个月后退休。 |
| **Elle est à la retraite depuis un an.** | 她已经退休一年了。 |

### 3. `quoi + 动词不定式`

**quoi** 可以作动词不定式的直接宾语，放在不定式前面。

| 法语 | 中文 |
|---|---|
| **On ne sait pas quoi acheter.** | 我们不知道买什么。 |
| **Je ne sais plus quoi dire.** | 我真不知道说什么好了。 |
| **Il ne sait quoi faire de ses dix doigts.** | 他简直不知道干什么好。 |

### 4. `pourquoi pas ... ?`

**pourquoi pas** 后面可以接名词、动词不定式、介词短语、代词等，用来提出建议：“为什么不……？”

| 法语 | 中文 |
|---|---|
| **Pourquoi pas un CD ?** | 为什么不送一张 CD 呢？ |
| **Pourquoi pas lui acheter un livre ?** | 为什么不给她买一本书呢？ |
| **Pourquoi pas chez moi ?** | 为什么不去我家呢？ |

### 5. 第二组规则 `-ir` 动词

法语第二组动词以 **-ir** 结尾，变位比较规则。

| 人称 | 词尾 | choisir 示例 |
|---|---|---|
| je | -is | je choisis |
| tu | -is | tu choisis |
| il/elle | -it | il/elle choisit |
| nous | -issons | nous choisissons |
| vous | -issez | vous choisissez |
| ils/elles | -issent | ils/elles choisissent |
| 过去分词 | -i | choisi |

> [!tip] 手写补充
> **rougir, agrandir, jaunir, finir, réussir** 都属于第二组规则动词。

### 6. 直接宾语人称代词 COD

直接宾语人称代词用于代替动词的直接宾语，也就是不需要介词引导的宾语。

| 单数 | 中文 | 复数 | 中文 |
|---|---|---|---|
| me / m' | 我 | nous | 我们 |
| te / t' | 你 | vous | 你们 / 您 |
| le / la / l' | 他 / 她 / 它 | les | 他们 / 她们 / 它们 |

### 7. 直接宾语代词的位置

| 结构 | 位置 | 例句 |
|---|---|---|
| 一般肯定句 | 放在相关动词前 | **Colette et sa sœur ? Je les connais.** |
| 一般肯定句 | 放在相关动词前 | **La musique, je l'aime beaucoup.** |
| 有不定式 | 放在不定式前 | **C'est un bon livre. Tu dois le prendre.** |
| 否定句 | **ne + 代词 + 动词 + pas** | **Il ne nous regarde pas.** / **Tu ne m'écoutes pas.** |
| 复合过去时 | 放在助动词前 | **Mon ami Farid l'a déjà lu.** |
| 复合过去时否定句 | **ne + 代词 + 助动词 + pas + 过去分词** | **Je ne t'ai pas vu hier.** |

> [!attention] 复合过去时配合
> 在以 **avoir** 为助动词的复合过去时里，如果直接宾语人称代词放在过去分词前，过去分词要与前置直接宾语在性、数上配合。教材提示第二册第 29 课会继续讲。

### 8. `e caduc` 哑音 e

发音练习关注一些句子里的 **e caduc**，也就是某些情况下会被弱化或省略的 **e**。

练习句：

| 法语 |
|---|
| **Je le connais.** |
| **Je ne sais pas.** |
| **On le voit.** |
| **Vous le faites.** |
| **Nous le savons.** |
| **Je ne mange pas ça.** |

### 第六单元补充：先看动词搭配，再选 COD / COI

| 搭配 | 宾语性质 | 代词替换与中文 |
|---|---|---|
| **connaître qn** | 直接宾语，没有介词 | **C'est ma prof, tu la connais ?** 这是我的老师，你认识她吗？ |
| **aimer qn** | 直接宾语 | **Lola, je t'aime.** Lola，我爱你。 |
| **manger qch** | 直接宾语，可以是物 | **Il y a des fruits sur la table, tu veux les manger ?** 桌上有水果，你想吃吗？ |
| **offrir qch à qn** | 礼物是直接宾语，收礼者是间接宾语 | 课文 **Qu'est-ce qu'on lui offre ?** 中，**lui** 是收礼者。 |

> [!note] 课件文字校对
> 第 14 页写作 **tu la connaît ?**；此处按主语 **tu** 记为 **tu la connais ?**。这只是例句变位的校正。

**-ir 结尾不等于第二组规则动词**。课件用 **choisir / finir** 对照：**je choisis / je finis；nous choisissons / nous finissons；ils choisissent / ils finissent**。**venir, partir, sortir, dormir, offrir** 等不能套这个模型。

**On ne sait pas quoi acheter.** = 我们不知道买什么。这里 **quoi** 是 **acheter** 的直接宾语，放在不定式前；不要与询问原因的 **pourquoi** 混淆。

## 快速复习

> [!summary] 复习目标
> - 会用 **Offrez-lui... / Pourquoi pas... / Vous pouvez...** 提建议。
> - 会区分 **lui** 是间接宾语代词，而 **le / la / les** 是直接宾语代词。
> - 会变位 **connaître** 和 **offrir**。
> - 会用第二组规则动词模型：**je choisis, nous choisissons, ils choisissent**。
> - 会把直接宾语代词放到正确位置：**je les connais**, **tu dois le prendre**, **je ne t'ai pas vu**。

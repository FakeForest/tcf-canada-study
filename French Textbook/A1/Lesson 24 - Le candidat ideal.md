# Lesson 24 - Le candidat idéal...

> [!info] 复习重点
> 这一课的主题是“理想的应聘者 / 面试建议”。语法重点是 **命令式**、**faire attention à**、**répondre à**，以及 **avec + 名词** 表示做事方式。

## 课文

### 如何成功通过面试？

**COMMENT RÉUSSIR UN ENTRETIEN ?** = 如何成功通过面试？

### 面试前

| 法语 | 中文 |
|---|---|
| **Recherchez des informations sur l'entreprise.** | 研究 / 查找企业的相关信息。 |
| **Passez une bonne nuit.** | 前一晚睡个好觉。 |
| **Faites attention à votre présentation générale : les vêtements, les cheveux...** | 注意你的整体仪表：衣着、头发等等。 |
| **Arrivez à l'heure.** | 准时到场。 |

### 面试中

| 法语 | 中文 |
|---|---|
| **Restez calme et souriant(e).** | 保持冷静，面带微笑。 |
| **Regardez dans les yeux la personne en face de vous.** | 注视你面前的人，也就是看着面试官的眼睛。 |
| **Écoutez avec attention et répondez avec des phrases courtes.** | 认真倾听，并用简短的句子回答。 |
| **Ne racontez pas votre vie ou vos problèmes.** | 不要讲述你的个人生活或私人问题。 |
| **Parlez correctement : n'utilisez pas de mots familiers.** | 得体地说话：不要使用过于随意的词语。 |
| **Posez, vous aussi, des questions : sur le travail, les horaires, l'entreprise.** | 你也要提一些问题：关于工作内容、工作时间和企业。 |

### 学会说：工作场合能不能做某事

| 法语 | 中文 |
|---|---|
| **Est-ce qu'on peut fumer ?** | 可以吸烟吗？ |
| **Est-ce qu'on peut dire tu au directeur ou à la directrice ?** | 可以对男 / 女经理用 **tu** 吗？ |
| **Est-ce qu'il faut arriver et partir exactement à l'heure ?** | 是否必须准确按时到达和离开？ |

## 语法

### 1. 命令式：用来给建议 / 提要求

课文里的面试建议大多使用 **vous** 命令式，语气像中文里的“请…… / 要……”。

| 动词不定式 | 命令式 | 中文 |
|---|---|---|
| rechercher | **Recherchez** | 请查找 / 研究 |
| passer | **Passez** | 请度过 |
| faire | **Faites** | 请做 / 请注意 |
| arriver | **Arrivez** | 请到达 |
| rester | **Restez** | 请保持 |
| regarder | **Regardez** | 请看 |
| écouter | **Écoutez** | 请听 |
| répondre | **Répondez** | 请回答 |
| utiliser | **Utilisez** | 请使用 |
| poser | **Posez** | 请提出 |

否定命令式结构是 **ne + 命令式动词 + pas**：

| 法语 | 中文 |
|---|---|
| **Ne racontez pas votre vie.** | 不要讲述你的个人生活。 |
| **N'utilisez pas de mots familiers.** | 不要使用随意的词语。 |

### 2. `faire attention à`

**faire attention à + 名词 / 名词短语 / 动词不定式** 表示“注意…… / 当心……”。

| 法语 | 中文 |
|---|---|
| **Faites attention à votre présentation générale.** | 注意你的整体仪表。 |
| **Faites attention à votre prononciation.** | 注意你们的发音。 |
| **Je fais toujours attention à ne pas déranger les autres.** | 我总是注意不打扰别人。 |
| **Fais attention à Paul, c'est un type dangereux.** | 当心 Paul，他是个危险的人。 |

### 3. `répondre à`

**répondre** 常和介词 **à** 连用，后面接“问题 / 信 / 某人”等。

| 法语 | 中文 |
|---|---|
| **Répondez avec des phrases courtes.** | 用简短句子回答。 |
| **répondre à une question** | 回答一个问题 |
| **répondre à une lettre** | 回一封信 |

### 4. `avec + 名词` 表示方式

**avec + 名词** 可以用来说明动作的方式，中文常译成“……地 / 用……方式”。

| 法语 | 中文 |
|---|---|
| **écouter avec attention** | 认真地听 |
| **répondre avec patience** | 耐心地回答 |
| **répondre avec ses propres mots** | 用自己的话回答 |
| **respirer avec peine** | 艰难地呼吸 |

### 5. `avant / pendant`

| 介词 | 中文 | 例子 |
|---|---|---|
| **avant** | 在……之前 | **avant l'entretien** = 面试前 |
| **pendant** | 在……期间 | **pendant l'entretien** = 面试中 / 面试期间 |

## 快速复习

> [!summary] 复习目标
> - 会把面试建议说成命令式：**Restez calme**, **Écoutez avec attention**, **Posez des questions**。
> - 会用 **faire attention à** 表示“注意…… / 当心……”。
> - 记住 **répondre à** 后面通常要带 **à**。
> - 看到 **avec attention / avec patience**，知道 **avec + 名词** 可以表示方式。
> - 能区分 **avant l'entretien**（面试前）和 **pendant l'entretien**（面试中）。

# Lesson 18 - Il est comment ?

> [!info] 复习重点
> 这一课开始正式使用 **复合过去时** 来讲述昨天/已经发生的事情。复习时抓住三件事：**avoir 变位 + 过去分词**、否定句位置、以及副词在复合过去时里的位置。

## 课文

### 对话：昨天做了什么

| 法语 | 中文 |
|---|---|
| **Alors, Fabien, qu'est-ce que tu as fait hier ?** | 那么，Fabien，你昨天做了什么？ |
| **Eh bien, j'ai fait les magasins.** | 嗯，我逛商店了。 |
| **Non ! Toi ?** | 不会吧！你？ |
| **Oui, oui. C'est pour le ski.** | 是的，是的。是为了滑雪。 |
| **Je pars à Val d'Isère dimanche.** | 我星期天去 Val d'Isère。 |
| **Et qu'est-ce que tu as acheté, alors ?** | 那你买了什么？ |
| **Eh bien, j'ai acheté ces chaussures.** | 嗯，我买了这双鞋。 |
| **Waouh ! Elles sont très jolies !** | 哇！它们很漂亮！ |
| **Ouais, bon... Ce sont des chaussures de ski, c'est tout !** | 嗯，好吧……这只是双滑雪鞋而已！ |
| **J'ai aussi pris un pull.** | 我还买了一件套头衫。 |
| **Il est comment, ton pull ?** | 你的套头衫是什么样的？ |
| **Tiens, regarde.** | 给你，看。 |
| **Ah oui, c'est un beau pull !** | 啊，是的，是件好看的套头衫！ |
| **Hum, hum... Il est très chaud.** | 嗯，嗯……它很暖和。 |
| **Et hier soir, qu'est-ce que tu as fait ?** | 那昨天晚上，你做了什么？ |
| **J'ai dîné dans un petit restaurant italien à côté de chez moi, avec ma sœur.** | 我和我姐姐/妹妹在我家旁边的一家意大利小餐馆吃了晚饭。 |
| **Il est bien, ce restaurant ?** | 这家餐馆好吗？ |
| **Très bien.** | 很好。 |
| **Il est simple, mais la cuisine est bonne.** | 它很朴素，但是饭菜很好。 |
| **Ma sœur a pris des pâtes et moi, j'ai mangé une pizza.** | 我姐姐/妹妹点了意面，我吃了一个披萨。 |
| **Et pour le dessert ?** | 甜点呢？ |
| **Nous n'avons pas pris de dessert.** | 我们没有吃甜点。 |
| **Et bien, moi, j'ai travaillé toute la journée et j'ai dîné seul !** | 哎，我呢，我工作了一整天，而且一个人吃了晚饭！ |

### 学会说：讲述过去和表达看法

| 交际功能 | 常用表达 | 中文 |
|---|---|---|
| 复述过去发生的事 | **J'ai fait les magasins.** | 我逛商店了。 |
| 询问过去买了什么 | **Qu'est-ce que tu as acheté ?** | 你买了什么？ |
| 表达观点 | **Ce restaurant est très bien.** | 这家餐馆很好。 |
| 表达观点 | **La cuisine est bonne.** | 饭菜很好。 |
| 表达观点 | **C'est un beau pull.** | 这是一件好看的套头衫。 |
| 描述衣物/物品 | **Il est comment, ton pull ?** | 你的套头衫是什么样的？ |
| 描述衣物/物品 | **Il est très chaud.** | 它很暖和。 |

## 语法

### 1. 复合过去时：`avoir / être + 过去分词`

复合过去时用来表示过去某个确定时间内发生并且已经结束的动作，或者说话前已经发生并结束、但和现在仍有关联的动作。

这一课先重点掌握 **avoir** 做助动词的情况：

| 主语 | `avoir` 现在时 | 例句 |
|---|---|---|
| j' | ai | **J'ai acheté un livre.** |
| tu | as | **Tu as mangé une pomme ?** |
| il/elle | a | **Il a pris le bus.** |
| nous | avons | **Nous avons fait les magasins.** |
| vous | avez | **Vous avez bien mangé ?** |
| ils/elles | ont | **Ils ont parlé.** |

> [!note] 记忆线索
> 复合过去时不是“一个词”，而是一个组合：**助动词 + 过去分词**。大多数及物动词和很多不及物动词都先用 **avoir**。

### 2. 过去分词

| 动词类型 | 过去分词规律 | 例子 |
|---|---|---|
| 第一组 `-er` 动词 | 去掉 `-er`，加 `-é` | **dîner -> dîné**, **manger -> mangé**, **acheter -> acheté** |
| 第二组 `-ir` 动词 | 去掉 `-ir`，加 `-i` | **finir -> fini**, **choisir -> choisi** |
| 不规则动词 | 需要单独记 | **faire -> fait**, **prendre -> pris**, **boire -> bu** |

常见不规则过去分词：

| 原形 | 过去分词 | 记忆提示 |
|---|---|---|
| avoir | eu | 常见 `u` 型 |
| être | été | 单独记 |
| faire | fait | `fait` |
| dormir | dormi | `i` 型 |
| partir | parti | `i` 型 |
| prendre | pris | `is` 型 |
| boire | bu | `u` 型 |
| lire | lu | `u` 型 |
| vendre | vendu | `u` 型 |
| voir | vu | `u` 型 |
| vivre | vécu | `u` 型 |
| écrire | écrit | `it` 型 |

### 3. 否定句：`ne...pas` 夹住助动词

复合过去时的否定句里，**ne...pas** 放在助动词两边，不夹过去分词。

| 肯定句 | 否定句 |
|---|---|
| **Ils ont parlé.** | **Ils n'ont pas parlé.** |
| **Nous avons pris un dessert.** | **Nous n'avons pas pris de dessert.** |

### 4. 疑问句：主语和助动词倒装

复合过去时做倒装疑问句时，倒装的是**主语和助动词**，不是过去分词。

| 普通问句 | 倒装问句 |
|---|---|
| **Tu as mangé une pomme ?** | **As-tu mangé une pomme ?** |
| **Vous avez pris un café ?** | **Avez-vous pris un café ?** |

### 5. 副词位置：放在助动词和过去分词之间

在复合过去时中，**aussi**, **toujours**, **beaucoup**, **trop**, **bien** 等常放在助动词和过去分词之间。

| 法语 | 中文 |
|---|---|
| **J'ai beaucoup travaillé ce week-end.** | 这个周末我做了很多工作。 |
| **As-tu bien mangé ?** | 你吃得好吗？ |
| **J'ai aussi pris un pull.** | 我还拿/买了一件套头衫。 |

## 快速复习

> [!summary] 复习目标
> - 能用 **j'ai + 过去分词** 说昨天做了什么。
> - 会把否定结构放在助动词两边：**je n'ai pas pris...**。
> - 会识别常见过去分词：**fait**, **pris**, **bu**, **vu**, **écrit**。
> - 会用 **Il est comment ?** 询问“它怎么样？”。

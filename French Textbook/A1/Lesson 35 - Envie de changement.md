# Lesson 35 - Envie de changement

> [!info] 复习重点
> 看房与装修：用 **si** 提出条件，用 **quand** 说明将来某个时间点。重点对照 **si + 现在时** 和 **quand + 简单将来时**，以及 **changer quelque chose / changer de quelque chose**。

## 课文

### 要不要买这套房？

| 法语 | 中文 |
|---|---|
| **Alors, qu'est-ce que tu en penses ?** | 那么，你觉得怎么样？ |
| **Ouais… J'aime bien.** | 嗯……我挺喜欢的。 |
| **Il est grand, il est clair… et puis, il est calme ; ça, c'est bien !** | 它很大、很明亮……而且很安静，这点很好！ |
| **Mais, si on l'achète, il faudra faire des travaux.** | 但是，如果买下来，就得装修。 |
| **Regarde, tu as vu la couleur des murs dans les chambres ?** | 看，你注意到卧室墙壁的颜色了吗？ |
| **La couleur des murs, ce n'est pas un problème : un peu de peinture et puis c'est bon !** | 墙壁颜色不是问题：刷点油漆就好了！ |
| **Oui, d'accord, mais le salon et la salle à manger sont un peu petits, non ?** | 是，没错，不过客厅和餐厅有点小，不是吗？ |
| **Tu sais, si on supprime le mur entre ces deux pièces, ça fera un grand salon…** | 你看，如果拆掉这两个房间之间的墙，就能变成一个大客厅…… |
| **On pourra facilement mettre tous nos meubles.** | 我们就能轻松放下所有家具。 |
| **C'est vrai, tu as raison.** | 是的，你说得对。 |
| **Et quand on aura un peu d'argent, on pourra peut-être installer une cheminée, là dans le coin ?** | 等我们手头宽裕一些，也许能在那边角落安装一个壁炉？ |
| **Et pour la cuisine et la salle de bains ?** | 那厨房和浴室呢？ |
| **Écoute, ça, on verra plus tard !** | 听着，这些以后再说！ |
| **On changera peut-être la cuisine dans un an ou deux mais pas tout de suite !** | 也许一两年后会翻新厨房，但不是马上！ |
| **Ça va faire beaucoup de dépenses.** | 那会花很多钱。 |
| **Bon, alors, qu'est-ce qu'on fait ?** | 好，那我们怎么办？ |
| **On l'achète ou pas ?** | 买还是不买？ |

## 语法

### 1. `si + 现在时`：如果……

本课的条件从句用 **si + 直陈式现在时**。主句可以用现在时、简单将来时、最近将来时或命令式。

| 主句形式 | 第九单元例句 | 中文 |
|---|---|---|
| 现在时 | **Si tu veux, on se promène au bord de la mer.** | 如果你愿意，我们去海边散步。 |
| 简单将来时 | **S'il fait beau demain, j'irai au parc.** | 如果明天天气好，我就去公园。 |
| 最近将来时 | **Si Julie a du temps, elle va voyager à l'étranger.** | 如果 Julie 有时间，她就要出国旅行。 |
| 命令式 | **S'il fait froid, prends ton manteau.** | 如果天气冷，就带上外套。 |

课文：**Si on l'achète, il faudra faire des travaux.** 前半是条件，后半是结果。虽然谈的是将来，**si** 后仍是 **achète**，主句才用 **faudra**。**si + il** 省音为 **s'il**。

### 2. `quand`：当……的时候

**quand** 引导时间从句。描述将来的事情时，从句可以用简单将来时：

| 法语 | 中文 | 观察点 |
|---|---|---|
| **Quand j'étais petite, on habitait à la campagne.** | 我小时候，我们住在乡下。 | 过去背景：未完成过去时。 |
| **Quand on aura un peu d'argent, on pourra peut-être installer une cheminée.** | 等有点钱时，我们也许能安装壁炉。 | 将来：**aura + pourra**。 |
| **Quand tu finiras ce travail, tu pourras prendre des vacances.** | 等你完成这项工作，就可以休假了。 | 将来：**finiras + pourras**。 |

> [!tip] 一起对照记
> **si** 是“如果”，本课条件结构中从句用现在时；**quand** 是“当 / 等到”，谈将来时从句可以用将来时。教材说这里的 **quand** 也带有“等条件达成”的意味，但两者的时态不能照搬。

> 来源：[[taxi_1学生用书9.23.pdf#page=186|教材第 186 页：si 与 quand]]、[[你好法语A1第九单元.pdf#page=21|课件第 21 页：四类主句与 quand]]。

### 3. `changer + 名词` 与 `changer de + 名词`

| 结构 | 本课例子 | 中文 |
|---|---|---|
| **changer + 带限定词的名词** | **changer la cuisine** | 翻新厨房，更换厨房设施。 |
| 同上 | **changer l'ampoule / les pneus / les draps / les meubles** | 换灯泡 / 轮胎 / 床单 / 家具。 |
| **changer de + 不带冠词的名词** | **changer de voiture** | 换一辆车。 |
| 同上 | **changer de profession / d'appartement** | 换职业 / 换住所。 |
| 同上 | **changer de sujet / d'idée** | 换话题 / 改主意。 |

课件用“东西不好了需要换掉”和“不改变属性的更换”帮助区分。复习时优先记具体搭配：**changer les pneus** 是更换轮胎，**changer de voiture** 是换另一辆车，不把提示概括成所有语境都适用的定义。

**On va faire un peu de changement chez nous.** = 我们打算让家里有些变化。这里 **changement** 是名词；**changer** 是动词。

> 来源：[[taxi_1学生用书9.23.pdf#page=185|教材第 185 页：changer 注释]]、[[你好法语A1第九单元.pdf#page=20|课件第 20 页：两种搭配]]。

### 4. `avoir envie de` 与家具、装修表达

**avoir envie de + 名词 / 不定式** 表示“想要…… / 想做……”，课件用 **vouloir + 名词 / 不定式** 对照理解。注意前者有 **de**，后者直接接宾语或不定式。

| 课文 / 课件表达 | 中文 |
|---|---|
| **installer une cheminée** | 安装一个壁炉。 |
| **mettre tous nos meubles** | 放下我们所有的家具。 |
| **supprimer le mur entre ces deux pièces** | 拆掉两间房之间的墙。 |
| **ça fera un grand salon** | 这样会形成一个大客厅；这里 **faire** 表示形成、构成。 |
| **Ça va faire beaucoup de dépenses.** | 这将造成很多开销。 |

**à** 可以表示用途：**une salle à manger**（餐厅）、**une machine à laver**（洗衣机）、**un service à thé**（一套茶具）、**une boîte aux lettres**（信箱）。

### 5. 对话中的插入语

**Tu sais… / Vous savez…** 可用来强调自己的想法、提醒对方；**Écoute… / Écoutez…** 用来引起注意，在课文里也引出“以后再说”的回应。**Qu'est-ce que tu en penses ?** 中的 **en** 指对这套房子的看法，联动 [[Lesson 33 - Beau fixe#语法|第 33 课：penser de → en]]。

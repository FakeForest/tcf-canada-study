# Lesson 19 - Chère Léa...

> [!info] 复习重点
> 这一课继续复合过去时，重点换成 **être 做助动词** 的动词：表示来去、进出、上升下降、出生死亡、停留、跌落、变化等。用 **être** 时，过去分词要和主语做性数配合。

## 课文

### 明信片：在巴塞罗那

| 法语 | 中文 |
|---|---|
| **Chère Léa,** | 亲爱的 Léa： |
| **Étienne et moi, nous sommes à Barcelone pour le week-end, chez Alicia.** | Étienne 和我周末在巴塞罗那，住在 Alicia 家。 |
| **Nous sommes arrivés vendredi en avion.** | 我们星期五坐飞机到了。 |
| **Samedi, Alicia et moi, nous sommes allées faire des courses.** | 星期六，Alicia 和我去购物了。 |
| **Nous avons marché toute la journée.** | 我们走了一整天。 |
| **Le soir, nous sommes allés au restaurant tous les trois.** | 晚上，我们三个人一起去了餐馆。 |
| **Nous sommes rentrés à deux heures du matin.** | 我们凌晨两点回来的。 |
| **Nous avons passé une excellente soirée !** | 我们度过了一个非常棒的夜晚！ |
| **Ce matin, nous avons visité le musée Picasso.** | 今天上午，我们参观了毕加索博物馆。 |
| **Et, cet après-midi, nous sommes allés au parc Güell !** | 今天下午，我们去了古埃尔公园！ |
| **C'est magnifique !** | 太美了！ |
| **Nous rentrons dans deux jours.** | 我们两天后回去。 |
| **À bientôt. Bisous,** | 回头见，亲亲， |
| **Mathilde** | Mathilde |

### 学会说：谈论过去事件、询问时间和时长

| 交际功能 | 常用表达 | 中文 |
|---|---|---|
| 谈论已经过去的事情 | **Nous sommes arrivés vendredi soir.** | 我们星期五晚上到了。 |
| 谈论已经过去的事情 | **Ils sont rentrés hier.** | 他们昨天回来了。 |
| 询问时间点 | **Ils sont arrivés quand ?** | 他们什么时候到的？ |
| 回答时间点 | **Aujourd'hui.** | 今天。 |
| 回答时间点 | **La semaine dernière.** | 上周。 |
| 询问时长 | **Tu es restée combien de temps ?** | 你待了多长时间？ |
| 回答时长 | **Cinq jours.** | 五天。 |
| 询问离开多久 | **Ils sont partis pour combien de temps ?** | 他们离开多长时间？ |
| 回答离开多久 | **Pour deux jours.** | 两天。 |
| 询问多久以后 | **Tu reviens quand ?** | 你什么时候回来？ |
| 回答多久以后 | **Dans une semaine.** | 一周后。 |

### 课本注释

| 表达 | 说明 |
|---|---|
| **Étienne et moi** | 法语说“我和某人”时，**moi** 一般放最后；作主语时谓语用复数第一人称。 |
| **tous les trois** | 三个人一起；如果三个人都是女性，可用 **toutes les trois**。 |
| **Parc Güell** | 古埃尔公园，位于巴塞罗那，由 Gaudí 设计。 |
| **dans deux jours** | 两天后；**dans + 一段时间** 表示“从现在算起……之后”。 |

## 语法

### 1. 复合过去时：`être + 过去分词`

这一课的重点是用 **être** 做助动词的复合过去时。它们大多是不及物动词，而且常和方向、移动、状态变化有关。

| 动词组 | 过去分词 |
|---|---|
| aller / venir | allé(e) / venu(e) |
| entrer / sortir | entré(e) / sorti(e) |
| arriver / partir | arrivé(e) / parti(e) |
| monter / descendre | monté(e) / descendu(e) |
| naître / mourir | né(e) / mort(e) |
| rester | resté(e) |
| tomber | tombé(e) |
| devenir | devenu(e) |

> [!important] 配合规则
> 用 **être** 做助动词时，过去分词要和主语的性、数保持一致：阴性加 **-e**，复数加 **-s**，阴性复数加 **-es**。

| 法语 | 中文 | 配合点 |
|---|---|---|
| **Elle est arrivée vendredi.** | 她星期五到的。 | **elle** 阴性，所以 **arrivée** |
| **Mathilde et Alicia sont allées faire des courses.** | Mathilde 和 Alicia 去购物了。 | 两位女性，所以 **allées** |
| **Sophie et Étienne sont allés au restaurant.** | Sophie 和 Étienne 去餐馆了。 | 男女混合，用阳性复数 **allés** |

### 3. 副代词 `y` 在复合过去时中的位置

副代词 **y** 用来代替地点状语。复合过去时中，**y** 放在助动词前面。

| 法语 | 中文 |
|---|---|
| **On y est allé deux fois.** | 我们去过那里两次。 |
| **Vous êtes allés chez elle ?** | 你们去她家了吗？ |
| **Non, on n'y est pas allé.** | 没，我们没去那里。 |
| **Paris ? J'y ai vécu plusieurs années.** | 巴黎？我在那里住了好几年。 |

### 4. `pour` 和 `dans + 一段时间`

| 结构 | 用法 | 例句 |
|---|---|---|
| **pour + 一段时间** | 表示动作发生以后，预计其进程、结果或影响将持续多久 | **Ils sont partis pour trois mois.** 他们离开三个月。 |
| **dans + 一段时间** | 以说话时间为起点，表示“……以后” | **Ils rentrent dans une semaine.** 他们一周以后回来。 |

## 快速复习

> [!summary] 复习目标
> - 会区分 **avoir + 过去分词** 和 **être + 过去分词**。
> - 记住常见 être 动词：**aller, venir, entrer, sortir, arriver, partir, monter, descendre, naître, mourir, rester, tomber, devenir**。
> - 用 être 时，过去分词要和主语做性数配合。
> - 会用 **dans deux jours** 表示“两天后”，用 **pour deux jours** 表示“持续两天”。

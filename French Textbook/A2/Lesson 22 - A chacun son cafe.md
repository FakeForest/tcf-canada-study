# A2 Lesson 22 - À chacun son café

> [!info] 本课重点
> 介绍不同类型的咖啡馆，再用 **à cause de**、**grâce à**、**parce que** 或 **comme** 解释原因。课文中的数量是教材历史资料，文中的 **aujourd'hui** 指撰文时，不是当前统计。

## 课文

### 1. 咖啡馆为什么越来越少？

| 法语原句 | 中文理解 |
|---|---|
| En 1910, il y avait 510 000 cafés et bars en France. | 1910 年，法国有 51 万家咖啡馆和酒吧。 |
| En 1960, il y en avait encore 200 000. | 1960 年，还有 20 万家。 |
| Aujourd'hui, il n'en reste plus que 49 000. | 到文中所说的“如今”，只剩 4.9 万家。 |
| Comment expliquer la disparition de presque 6 000 bistrots chaque année ? | 怎么解释每年有近 6000 家小咖啡馆消失的现象？ |

### 2. 新式咖啡馆

| 法语原句 | 中文理解 |
|---|---|
| Les cafés traditionnels vous ennuient ? | 传统咖啡馆让你觉得无聊吗？ |
| Vous recherchez un lieu original pour sortir seul(e) ou entre amis ? | 想找个有新意的地方，一个人出去坐坐或和朋友聚聚吗？ |
| Voici quelques endroits qui pourront peut-être vous intéresser. | 下面这些地方也许会让你感兴趣。 |
| **Pour bronzer : Le Sun Café** | 想晒黑一点：阳光咖啡馆 |
| Vous déprimez à cause du manque de soleil et vous aimeriez être un peu plus bronzé(e) ? | 你因为缺少阳光而情绪低落，想晒得黑一点吗？ |
| **Pour voyager : Le Jungle Café** | 想体验异国风情：丛林咖啡馆 |
| Vous adorez les musiques exotiques ? | 你特别喜欢异国风情的音乐吗？ |
| Ce café est fait pour vous ! | 这家咖啡馆就是为你开的！ |
| **Pour éduquer : Le Café de l'École des parents** | 想交流育儿经验：父母学堂咖啡馆 |
| Vous voulez parler de votre premier bébé, de l'école ou de jeux pour enfants ? | 你想聊聊自己的第一个宝宝、学校，或是适合小朋友的游戏吗？ |
| **Pour lire : Le Café des Mots** | 想阅读：文字咖啡馆 |
| Vous avez envie de prendre un verre et de lire un roman en même temps ? | 想一边喝点东西，一边读小说吗？ |
| C'est très facile ! | 很简单！ |
| **Pour surfer : Le Cybercafé** | 想上网：网络咖啡馆 |
| Vous avez envie de prendre un verre avec Luis à Mexico ou Emiko à Tokyo ? | 你想和在墨西哥城的路易斯，或在东京的惠美子一起喝一杯吗？ |

### 3. 街头访谈：人们为什么去或不去？

| 法语原句 | 中文理解 |
|---|---|
| Pardon, monsieur, comment expliquez-vous la disparition de nombreux cafés en France ? | 打扰一下，先生，您怎么看法国许多咖啡馆消失的现象？ |
| Pour moi, le problème, c'est la télé. | 在我看来，问题出在电视。 |
| Le soir, les gens préfèrent rester chez eux devant un film ou une émission et puis voilà, c'est tout. | 晚上大家更愿意待在家里看电影或节目，就这么回事。 |
| C'est… c'est dommage parce que, dans un café, on rencontre des gens, on discute… | 这……真可惜，因为在咖啡馆能遇见别人，还能聊聊天…… |
| Devant sa télé, c'est pas pareil. | 坐在自家电视机前可不一样。 |
| Ah, ben, euh… Nous, on aimerait bien aller plus souvent dans les bars pour faire la fête mais c'est pas possible à cause des prix. | 嗯……我们其实挺想多去酒吧聚聚，但因为价格太高，没法常去。 |
| C'est vrai quoi… quand tu vois le prix d'un verre… eh bien… moi, je dis : « C'est beaucoup trop cher ! » | 真的嘛……看到一杯饮料多少钱……嗯，我只想说：“实在太贵了！” |
| Moi, j'adore aller prendre un verre dans un café. | 我特别喜欢去咖啡馆喝一杯。 |
| C'est sympa, tu rencontres des amis, tu parles. | 挺不错的，能见到朋友，还能聊聊天。 |
| C'est bien, non ?… | 这不挺好吗？…… |
| Mais c'est vrai aussi qu'aujourd'hui beaucoup de cafés se ressemblent. | 不过现在很多咖啡馆都很像，这也是真的。 |
| Et puis, on ne peut plus fumer à l'intérieur maintenant ! | 而且，现在室内也不能抽烟了！ |
| Ce sont les habitudes des jeunes qui ont changé. | 变的是年轻人的习惯。 |
| Regardez autour de vous… | 看看你周围…… |
| Il n'y a plus que des fast-foods. | 只剩快餐店了。 |
| Je trouve ça triste ! | 我觉得这挺让人难过的！ |
| Moi, je vais toujours dans le même café, à côté de chez moi. | 我总去家附近同一家咖啡馆。 |
| Tout le monde se connaît, c'est bien. | 大家彼此都认识，这样挺好。 |
| Mais souvent, dans les autres cafés, les serveurs ne sont pas sympas. | 但在其他咖啡馆，服务员常常没那么友好。 |

> 来源：[[你好法语2-11.23.pdf#page=123|教材第 123 页：访谈与注释]]。原文中的 **c'est pas** 是省略 **ne** 的口语，书面复习写 **ce n'est pas**。

## 单词

| 法语 | 中文与用法 |
|---|---|
| un bistrot ; un cybercafé | 小咖啡馆、小酒馆；能上网的咖啡馆。 |
| original(e) ; traditionnel(le) | 新颖的（手写）；传统的。 |
| déprimer [depress] ; bronzer ; bronzé(e) | 情绪低落（方括号为手写英文释义）；晒黑；晒成棕色的。 |
| un accès ; avoir accès à ; être accessible à | 进入、使用的途径；能进入或使用；对……开放、可及（后两项为手写搭配）。 |
| disparaître ; une disparition ; il reste… | 消失（动词）；消失（名词）；还剩…… |
| (s')ennuyer ; s'installer | 让人厌烦／自己觉得无聊；坐下来、安顿下来。 |
| un concert ; un roman ; un sujet | 一场音乐会；一本小说；一个话题。 |
| exotique ; cubain(e) ; les UV | 异国风情的；古巴的；紫外线。 |
| de mémoire ; en même temps ; toutes les semaines | 凭记忆；同时；每周（手写）。 |
| à l'intérieur / à l'extérieur | 在里面／在外面（手写对照）。 |
| pareil(le) ; se ressembler | 一样的、相似的；彼此相像。**C'est pas pareil.** 那不一样。 |
| C'est dommage ! [what a pity] | 真可惜！（方括号为手写英文释义。） |
| Comme ci, comme ça. [so-so] | 一般般、马马虎虎（手写补充）。 |

**ennuyer** 现在时：**j'ennuie, tu ennuies, il/elle ennuie, nous ennuyons, vous ennuyez, ils/elles ennuient**。过去分词 **ennuyé**。

## 语法

### 1. 表达原因：先看后面接什么

| 结构 | 用法 | 教材例句 |
|---|---|---|
| **à cause de + 名词／重读人称代词** | 因为、由于；本课主要用于说明负面结果。 | À cause de lui, l'affaire a manqué. 因为他，事情失败了。 |
| **grâce à + 名词／重读人称代词** | 多亏、幸亏（手写英文 **[thanks to]**）；通常引出好结果。 | Nous avons gagné ce match grâce à toi. 多亏了你，我们赢了这场比赛。 |
| **parce que + 从句** | 因为；最常用，一般先说结果再说原因。 | Il est tombé parce que le chemin est glissant. 因为路滑，他摔倒了。 |
| **comme + 从句** | 因为、既然（手写英文 **[since]**）；通常放句首，先交代原因。 | Comme elle arrive demain, il faut préparer une chambre. 她明天就到，所以得准备一间房。 |

用两句也可以说明原因：**On n'y va plus à cause des prix. C'est trop cher.** 因为价格，我们不再去了。太贵了。

> 来源：[[你好法语2-11.23.pdf#page=122|教材第 122 页：原因表达]]。

### 2. 课文句型

- **À chacun son / sa…** 各有各的……，物主限定词跟后面的名词配合：**à chacun son goût** 各有各的口味；**à chacun sa tasse** 各取各杯。
- **Votre verre à la main, installez-vous…** 表示坐下时的状态：端着杯子。类似 **Il se promène les mains dans les poches.** 他把手插在口袋里散步。
- **comme si + 未完成过去时**：把假想的情形说成“好像……一样”。**Il me regarde comme s'il ne me connaissait pas.** 他看我的样子仿佛不认识我。
- **C'est dommage de + 不定式**：做某事真可惜。**C'est dommage d'abattre de si beaux arbres !** 砍掉这么漂亮的树，真可惜！
- **il n'en reste plus que 49 000**：只剩 4.9 万家。**en** 指前面提到的咖啡馆和酒吧；**ne… plus que** 表示“现在只剩……”，不是“一点也不剩”。

> 来源：[[你好法语2-11.23.pdf#page=120|教材第 120 页：课文与注释]]、[[你好法语2-11.23.pdf#page=123|第 123 页：c'est dommage]]。

## 快速复习

- 价格高所以不去：**à cause des prix**；多亏有这家咖啡馆：**grâce à ce café**。
- 原因是完整句子时，比较 **parce que** 放在结果后和 **comme** 放句首。
- 用 **avoir envie de prendre un verre**、**sortir entre amis**、**prendre un verre en même temps que…** 说说你想怎样度过空闲时间。

# A2 Lesson 2 - De mère en fille

> [!info] 本课重点
> 从人物介绍和三代人的访谈复习**最近过去时、最近将来时**和 **tout**。课文中关于人物、作品和年份的说法均按教材当时的文本记录，不代表近况。

## 课文

### 1. 人物介绍：Charlotte Gainsbourg

| 法语原句 | 中文理解 |
|---|---|
| Charlotte Gainsbourg est la femme de l'acteur Yvan Attal, la fille de Jane Birkin (actrice et chanteuse d'origine anglaise) et de Serge Gainsbourg (musicien et chanteur français). | 夏洛特·甘斯布是演员伊万·阿达勒的妻子，也是英国裔演员兼歌手简·伯金和法国音乐人兼歌手塞尔日·甘斯布的女儿。 |
| Elle a deux sœurs : Kate (photographe) et Lou (actrice). | 她有两个姐妹：摄影师凯特和演员卢。 |
| Sa grand-mère, Judy Campbell, et son oncle, Andrew Birkin, font aussi du cinéma. | 她的外祖母朱迪·坎贝尔和舅舅安德鲁·伯金也从事电影工作。 |
| Elle et son mari ont deux enfants : un fils, Ben, né en 1997, et une fille, Alice, née en 2002. | 她和丈夫有两个孩子：1997 年出生的儿子本，以及 2002 年出生的女儿爱丽丝。 |
| Vingt ans après son premier album Charlotte Forever, elle vient de sortir un album en anglais, 5:55, avec le groupe Air. | 首张专辑《Charlotte Forever》推出 20 年后，她刚与 Air 乐队发行了英语专辑《5:55》。 |
| Lola, Judith, Lucy, Jane Eyre, Camille ou Mila, Charlotte Gainsbourg a déjà joué 30 personnages différents au cinéma, en français ou en anglais. | 无论是洛拉、朱迪丝、露西、简·爱、卡米耶还是米拉，夏洛特已在法语或英语电影中演过 30 个不同角色。 |
| Elle a joué avec son mari dans Ma femme est une actrice (2001). | 她曾与丈夫共同出演 2001 年的电影《我的妻子是演员》。 |
| Elle va bientôt jouer dans Les Sabines, le prochain film d'Yvan Attal. | 她不久后将出演伊万·阿达勒的下一部电影《Les Sabines》。 |
| Passionnée de mode, Charlotte a fait en 2003 de la publicité pour les vêtements du créateur Gérard Darel et va souvent aux défilés de Haute Couture. | 夏洛特热爱时尚；她曾于 2003 年为设计师热拉尔·达雷尔的服装拍广告，也常参加高级定制服装秀。 |

> 来源：[[你好法语2-10.21.pdf#page=16|教材第 16 页：人物介绍与手写批注]]。**vient de sortir** 是“刚发行”，**va bientôt jouer** 是教材写作当时的“即将出演”，不要当作现在的动态。

### 2. 三代粉丝的谈话

> Morgane（16 岁）、妈妈 Isabelle 和外婆 Catherine 都喜欢 Charlotte。下面按教材对话逐句复习。

| 法语原句 | 中文理解 |
|---|---|
| J'adore tous ses films ! | 她所有的电影我都喜欢！ |
| Elle peut jouer des personnages très différents et elle est toujours parfaite. | 她能演各种不同的角色，而且总是演得很好。 |
| Ah oui ! Je viens de revoir le film Ma femme est une actrice à la télé. | 是啊！我刚在电视上重看了《我的妻子是演员》。 |
| Elle est magnifique cette fille ! | 她真棒啊，这个姑娘！这里把 **cette fille** 放在句末作口语强调。 |
| Je comprends pourquoi tout le monde est amoureux d'elle dans ce film. | 我明白为什么电影里人人都爱上她。 |
| Moi, mon film préféré avec Charlotte Gainsbourg, c'est Golden Door, un film franco-italien de 2006. | 对我来说，最喜欢她出演的电影是 2006 年的法意合拍片《Golden Door》。 |
| Oui ! Je me souviens. J'aime beaucoup ce film ! | 对！我记得。我很喜欢这部电影！ |
| Hum… Je ne suis pas d'accord. | 嗯……我不同意。 |
| Le film n'est pas très bon mais elle, elle est fantastique. | 电影不算太好，但她演得很棒。 |
| Elle va bientôt sortir un nouveau film, non ? | 她快要有新电影上映了，对吧？ |
| Oui, oui. Un film d'Yvan Attal, son mari. | 对，对，是她丈夫伊万·阿达勒的电影。 |
| Le film va s'appeler… Les Sabines. | 电影会叫……《Les Sabines》。 |
| Oui, c'est ça, Les Sabines. | 对，就是《Les Sabines》。 |
| Ah oui ! C'est super ! | 啊，对！太好了！ |
| Et son album, qu'est-ce que vous en pensez ? | 那她的专辑，你们觉得怎么样？**en** 指前面提到的专辑。 |
| Bah… J'ai écouté toutes les chansons deux ou trois fois et je ne suis pas fan. | 嗯……所有歌我都听了两三遍，但我不是很喜欢。 |
| Je préfère l'actrice. | 我更喜欢她作为演员的一面。 |
| Ah bon ! Tu n'aimes pas ! | 啊，真的？你不喜欢吗！ |
| Alors moi, je viens d'écouter l'album toute la journée à la maison et il est vraiment bien ! | 可我刚在家听了这张专辑一整天，真的很好听！ |
| Tu as raison, mamie, il est vraiment super cet album ! | 外婆，你说得对，这张专辑真棒！ |

> 来源：[[你好法语2-10.21.pdf#page=20|教材第 20 页：访谈文字与中文对照]]。**franco-italien** 表示法意之间的关系；手写类比 **la relation sino-française / franco-chinoise**。

## 单词

| 法语 | 中文与用法 |
|---|---|
| **la mère / la fille / la grand-mère / la mamie** | 母亲 / 女儿 / 外祖母或祖母 / 外婆或奶奶的亲昵称呼。 |
| **l'oncle**（m.） / **la tante** | 叔舅伯姨等男性 / 女性亲属。 |
| **l'origine**（f.） / **d'origine anglaise** | 出身、来源 / 英国裔的。 |
| **le chanteur / la chanteuse** | 男歌手 / 女歌手。 |
| **le photographe / la photographe** | 摄影师，冠词区分性别。 |
| **le créateur / la créatrice** | 创作者、设计师。 |
| **le personnage / jouer un personnage** | 角色 / 扮演角色。**jouer** 也可指演奏、玩。 |
| **différent / différente** | 不同的；**30 personnages différents**。 |
| **être passionné(e) de** | 热爱……；教材 **passionnée de mode**，课件另举 **passionnée de film**。 |
| **la mode / être à la mode** | 时尚 / 很时髦；教材手写“她很时尚”：**elle est à la mode**。 |
| **le défilé / la Haute Couture** | 时装秀 / 高级定制服装。 |
| **l'album**（m.） / **la chanson** | 专辑 / 歌曲。 |
| **naître / né(e) / la naissance / la renaissance** | 出生 / 已出生的 / 出生 / 复兴、重生。 |
| **revoir** | 再看、重看；**venir de revoir un film**，刚重看一部电影。 |
| **bien / vraiment bien** | 好 / 真的很好；**bien** 在这里修饰对专辑的评价。 |

## 语法

### 1. 刚刚发生与即将发生

| 结构 | 例句 | 中文 |
|---|---|---|
| **venir 的现在时 + de + 动词原形** | Charlotte **vient de sortir** un album. | 夏洛特刚推出一张专辑。 |
| **venir 的未完成过去时 + de + 动词原形** | Nous **venions d'entrer** dans la maison quand l'orage a éclaté. | 暴风雨来时，我们刚进屋。叙述过去某时“刚刚”。 |
| **aller 的现在时 + 动词原形** | Elle **va bientôt jouer** dans un film. | 她很快将出演一部电影。 |
| **aller 的未完成过去时 + 动词原形** | Je savais qu'il **allait nous écrire**. | 我知道他那时要给我们写信。叙述过去某时“将要”。 |

代词的位置看原形动词：**Je viens de lui offrir un cadeau**（我刚送给他/她一份礼物），**Il va m'acheter une nouvelle voiture**（他将给我买一辆新车），**Elle va en parler avec ses amis**（她将和朋友谈这件事）。自反代词也跟原形动词：**Elle va se marier dans trois ans**。

> 来源：[[你好法语2-10.21.pdf#page=17|教材第 17 页：基本结构]]；[[你好法语2-10.21.pdf#page=18|教材第 18 页：过去参照点及代词位置]]；[[你好法语A2第一单元.pdf#page=7|课件第 7 页：U1L2]]。

### 2. tout：先判断词性，再做性数配合

| 用法 | 形式与教材例句 | 中文理解 |
|---|---|---|
| 形容词，跟名词配合 | **tout** homme, **toute** question, **tous** mes amis, **toutes** les chansons | 任何一个人、任何问题、我所有朋友、所有歌曲。四种形式：tout / toute / tous / toutes。 |
| 带限定词的单数 | **tout le livre**, **toute une semaine** | 整本书、整整一周。 |
| 带限定词的复数 | **tous les soirs** | 每天晚上；这里是规律性的“每”。 |
| 代词，替代整体 | Elle avait **tout**. / **Tous** sont venus. | 她拥有一切。/ 所有人都来了。 |
| 代词，指女性复数 | Céline et sa mère sont **toutes** fans. | 塞琳和妈妈两人都是粉丝。 |
| 名词 | **un tout** | 一个整体。 |
| 副词 | Il est **tout** heureux. / Elle est **toute** honteuse. | 他非常高兴。/ 她非常羞愧。副词修饰阴性且以辅音或嘘音 h 开头的形容词时，书中展示配合形式。 |

**否定范围要看清：**教材的 **Tous les étudiants ne mangent pas du poisson** 表示“并非所有学生都吃鱼”，不要直接理解为“没有学生吃鱼”。**tout le monde** 为“所有人”，语法上搭配单数动词：**tout le monde est amoureux d'elle**。

> 来源：[[你好法语2-10.21.pdf#page=18|教材第 18 页：tout 的词性、配合与例句]]；[[你好法语A2第一单元.pdf#page=8|课件第 8 页：形容词]]；[[你好法语A2第一单元.pdf#page=10|课件第 10 页：代词]]；[[你好法语A2第一单元.pdf#page=12|课件第 12 页：副词]]。课件第 14 页为听力/填空，不补造答案。

## 快速复习

- **刚做完**：Je **viens de revoir** le film. / 我刚重看了这部电影。
- **马上要做**：Elle **va sortir** un film. / 她将推出一部电影。
- **所有歌曲**：**toutes les chansons**；**一整天**：**toute la journée**；**大家**：**tout le monde**。

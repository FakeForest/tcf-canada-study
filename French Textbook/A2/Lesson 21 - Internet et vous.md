# A2 Lesson 21 - Internet et vous

> [!info] 本课重点
> 用法语谈自己上网做什么；区分“不”“还没”“从不”“不再”“什么也没有”和“一个人也没有”。

## 课文

### 1. 上网习惯问卷

| 法语原文 | 中文理解 |
|---|---|
| Quelles opérations réalisez-vous le plus sur Internet ? | 你在网上最常做哪些事？ |
| Acheter (des livres, des CD, des billets d'avion ou de train…) | 买东西（书、CD、机票或火车票等） |
| Dialoguer en direct | 实时聊天 |
| Écouter la radio | 听广播 |
| Jouer à des jeux | 玩游戏 |
| Lire et envoyer des e-mails | 阅读和发送邮件 |
| Rechercher des informations | 搜索信息 |
| Regarder (la télévision, des films…) | 看电视、电影等 |
| Télécharger (des jeux, de la musique, des vidéos…) | 下载游戏、音乐、视频等 |
| Autre | 其他 |
| Je n'utilise jamais Internet. | 我从不上网。 |

> 来源：[[你好法语2-11.23.pdf#page=116|教材第 116 页：问卷和词汇]]。

### 2. 五位受访者的上网习惯

| 法语原句 | 中文理解 |
|---|---|
| **第一位：下载音乐** | |
| Moi, je suis un fan de musique mais aujourd'hui, je n'achète plus de CD. | 我是个音乐迷，但现在不再买 CD 了。 |
| Je préfère acheter et télécharger les albums sur Internet. | 我更喜欢在网上购买并下载专辑。 |
| C'est moins cher et c'est plus rapide. | 这样更便宜，也更快。 |
| Et après, j'enregistre tout sur mon lecteur MP3. | 然后我把它们全存到 MP3 播放器里。 |
| **第二位：查资料** | |
| Internet, c'est parfait pour trouver des informations rapidement. | 要快速查找信息，上网再合适不过了。 |
| Avant, les étudiants comme moi passaient beaucoup de temps dans les bibliothèques. | 以前，像我这样的学生会花很多时间泡图书馆。 |
| Aujourd'hui, c'est différent : on trouve tout sur Internet. | 现在不一样了：在网上什么都能找到。 |
| **第三位：网上找房** | |
| Pour faire des achats, c'est super ! | 用来购物，真是太棒了！ |
| Avec mon mari, nous avons trouvé notre nouvelle maison sur un site spécialisé. | 我和丈夫在一个专门的网站上找到了我们的新房子。 |
| Nous avons contacté directement les anciens propriétaires. | 我们直接联系了原房主。 |
| Nous avons visité la maison. | 我们去看了房子。 |
| Et voilà ! | 就这么简单！ |
| Financièrement, c'est plus intéressant. | 从经济上看，这样更划算。 |
| Pour celui qui achète, cela ne coûte rien sur le site. | 对买家来说，使用这个网站不用花钱。 |
| **第四位：和家人联系** | |
| Mes enfants habitent aux États-Unis et ils m'envoient souvent des photos des petits par mail. | 我的孩子们住在美国，经常用邮件发孙辈的照片给我。 |
| C'est pratique, je trouve. | 我觉得这样很方便。 |
| Et pour discuter, c'est mieux : on peut se voir. | 聊天也更好：可以看到彼此。 |
| Je n'ai pas encore de webcam mais je vais en acheter une. | 我还没有网络摄像头，但我打算买一个。 |
| **第五位：下班后想见人** | |
| Moi, je n'utilise jamais Internet à la maison parce que vous comprenez, je suis toujours devant mon ordinateur au bureau et je ne vois personne… | 我在家从不上网。你也明白，我在办公室总是对着电脑，一个人也见不到…… |
| Alors, pendant mon temps libre, j'ai besoin de rencontrer des gens. | 所以空闲的时候，我需要出去见见人。 |

> 来源：[[你好法语2-11.23.pdf#page=119|教材第 119 页：访谈原文和注释]]。

## 语法

### 1. 否定词的选择

| 结构 | 意思与常见对应词 | 教材例句 |
|---|---|---|
| **ne… pas** | 不、没有 | Il n'est pas venu lundi dernier. 上周一他没来。 |
| **ne… pas encore** | 还没；对应 **déjà**（已经） | Non, je ne l'ai pas encore acheté. 不，我还没买。 |
| **ne… jamais** | 从不、从未；常与 **déjà / toujours** 对比 | Non, je n'en ai jamais fait. 不，我从没买过。 |
| **ne… plus** | 不再；对应 **encore / toujours**（仍然） | Non, ils n'en ont plus. 不，他们已经没有了。 |
| **ne… rien** | 什么也不；对应 **quelque chose** | Non, nous n'avons rien acheté. 不，我们什么也没买。 |
| **ne… personne** | 一个人也没有；对应 **quelqu'un** | Non, il n'y a personne. 不，一个人也没有。 |

- 复合过去时注意助动词和代词的位置：**je ne l'ai pas encore acheté**、**je n'en ai jamais fait**。作宾语的 **rien** 在这里也位于助动词之后、过去分词之前：**nous n'avons rien acheté**。
- **personne、rien** 也可以当主语。这时它们在前，动词前仍有 **ne**，不再加 **pas**：**Personne ne fume dans l'hôpital.** 医院里没人抽烟。**Rien ne l'intéresse.** 什么都引不起他的兴趣。

> 来源：[[你好法语2-11.23.pdf#page=117|教材第 117 页：否定结构]]。

### 2. 完全否定与部分否定

| 完全否定 | 部分否定 |
|---|---|
| Il ne travaille pas. 他不工作。 | Il ne travaille pas beaucoup. 他工作不多。 |
| Il ne pleut jamais. 从来不下雨。 | Il ne pleut pas tous les jours. 不是每天都下雨。 |

**Toutes les phrases ne sont pas correctes.** 不是所有句子都对，不等于“没有一句是对的”。先看否定的是整件事，还是“很多”“每天”“所有”等范围。

> 来源：[[你好法语2-11.23.pdf#page=118|教材第 118 页：否定的范围]]。

## 快速复习

- “不再买 CD”用 **je n'achète plus de CD**；“还没有摄像头”用 **je n'ai pas encore de webcam**。
- “没买任何东西”用 **rien**；“没见到任何人”用 **personne**。
- 用受访者的说法复述一种上网习惯：**télécharger des albums**、**rechercher des informations** 或 **envoyer des photos par mail**。

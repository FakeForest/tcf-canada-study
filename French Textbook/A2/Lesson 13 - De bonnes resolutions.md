# A2 Lesson 13 - De bonnes résolutions

> [!info] 本课重点
> 用法语谈新年计划、坚定或犹豫的决心；掌握 **si + 未完成过去时 → 条件式现在时**，并区分 chaque、quelques、plusieurs、certain(s)、tout。教材与第四单元课件对照复习。

## 课文

### 1. 开始新年的五个好决定

| 法语原句 | 中文理解 |
|---|---|
| Cinq bonnes résolutions pour commencer l'année. | 开始新年的五个好决定。 |
| Je me cultive. | 我要提高自己的修养、增长见识。 |
| Lire, aller au théâtre, au cinéma ou dans les musées, c'est important pour sa vie professionnelle. | 阅读、看戏、看电影或参观博物馆，对职业生活很重要。 |
| Je pars plus tôt du bureau. | 我要更早离开办公室。 |
| Comment passer moins de temps au travail et penser plus à soi… | 怎样少花些时间工作，多为自己考虑…… |
| Je mange mieux le midi. | 我要在中午吃得更好。 |
| Quelles sont les règles pour avoir une bonne alimentation au travail ? | 工作时怎样遵循良好的饮食习惯？ |
| Je passe moins de temps sur ma messagerie. | 我要少花些时间在电子信息上。 |
| Quels sont les trucs pour devenir maître de sa messagerie ? | 有哪些窍门能让自己掌控电子信息，而不是被它牵着走？ |
| Je fais du sport. | 我要运动。 |
| Avoir une activité sportive, c'est important pour contrôler le stress. | 进行体育活动对于控制压力很重要。 |
| Ce qu'il faut faire avec Boris Beck. | 与 Boris Beck 一起了解该做些什么。 |

### 2. 巴黎人的新年决心

| 法语原句 | 中文理解 |
|---|---|
| Chaque année, c'est la même chose. | 每年都是一样。 |
| Le 1er janvier, on se souhaite une bonne année, une bonne santé et on prend tous de bonnes résolutions. | 一月一日，人们互祝新年快乐、身体健康，人人都许下好决心。 |
| Mais qui les respecte vraiment ? | 可谁真正坚持了呢？ |
| Anne Dutilleul a interviewé plusieurs Parisiens pendant la nuit de la Saint-Sylvestre. | Anne Dutilleul 在跨年夜采访了几位巴黎人。 |
| S'il vous plaît, vous avez pris des résolutions pour cette année ? | 请问，您为今年作了什么决定吗？ |
| Ah oui ! J'ai décidé d'aller plusieurs fois par semaine à la piscine… | 有！我决定每周去游泳好几次…… |
| Si je pouvais, j'arrêterais de fumer. | 要是能做到，我会戒烟。 |
| Mais bon, c'est vraiment difficile… Non, je ne sais pas… | 不过，真的很难……唉，我也不知道…… |
| Je vais peut-être essayer de faire régulièrement du sport. | 我也许会试着经常运动。 |
| Ce serait bien, non ? | 那应该不错，不是吗？ |
| Alors moi, cette année, j'ai décidé de me coucher plus tôt et de moins faire la fête avec mes copains. | 我今年决定早点睡，少跟朋友们聚会。 |
| Quoi ? Ouais, ouais… non mais vous verrez !! | 什么？对，对……你们就等着看吧！ |
| J'aimerais bien dépenser moins d'argent, arrêter d'acheter certains trucs inutiles. | 我想少花点钱，不再买某些没用的东西。 |
| Et puis, si j'avais le temps, j'aimerais aussi aller plus souvent au théâtre… | 而且要是有时间，我也想更经常去剧院…… |
| J'y vais trop rarement. | 我去得太少了。 |
| Euh… bien travailler à l'école… avoir de bonnes notes… et puis… euh… être gentil avec mes parents. | 嗯……在学校好好学习……取得好成绩……还有……对父母好些。 |
| Oh ! là ! là ! Tous les ans, c'est la même chose… | 哎呀！每年都一样…… |
| Je prends quelques bonnes résolutions et, après, je ne les respecte pas. | 我作了几个好决定，后来又不遵守。 |
| Alors maintenant, je n'en prends plus. | 所以现在我不再作了。en 代替 des résolutions。 |

## 单词

| 法语 | 中文与批注 |
|---|---|
| une résolution / prendre une résolution / respecter | 决心／下决心／遵守、坚持。 |
| décider de + 不定式 / arrêter de + 不定式 | 决定做……／停止做……。 |
| se cultiver / une messagerie / un truc inutile | 增长见识／电子信息系统／没用的东西。truc 也可以是“窍门”。 |

## 语法

### 1. 假设：si + 未完成过去时，主句用条件式现在时

从句提出假设，主句说“在这个条件下会怎样”。**si 从句不用条件式现在时**。

| 教材例句 | 时态与中文 |
|---|---|
| Si j'étais vous, je ferais autrement. | étais：未完成过去时；ferais：条件式。要是我是您，我会换个做法。 |
| Si elle avait le temps, elle ferait un peu de sport. | 要是她有时间，就会做点运动。 |
| S'il faisait beau demain, je vous accompagnerais à la Grande Muraille. | 要是明天天气好，我就陪你们去长城。 |
| Si je pouvais, j'arrêterais de fumer. | 要是能做到，我会戒烟。 |

未完成过去时在这里**不等于事情发生在过去**，而是把条件放在假设层面。教材区分“与现实相反的假设”和“在某条件下可能发生的情况”；结合上下文判断，不把所有句子都译成过去。

对照较现实的条件：**si + 现在时**，主句可以是现在时、最近将来时、简单将来时或命令式，如 **S'il continue comme ça, il va réussir.**（如果继续这样，他会成功。）这与 L13 的假设结构不同。条件式的构成可回看 [[French Textbook/A2/Lesson 07 - Une minute pour un projet|A2 第 7 课]]。

> 来源：[[你好法语2-11.23.pdf#page=74|教材第 74 页：条件式现在时（2）]]。

### 2. 泛指形容词：后面仍带名词

| 形式 | 核心用法 | 教材例子 |
|---|---|---|
| chaque | 强调一个个；后接单数名词 | chaque matin；chaque année |
| quelque / quelques | 某个／少数几个；复数也可与限定词合用 | quelque chose；ces quelques livres |
| plusieurs | 好几个；只有复数形式，不分阴阳性，前不加冠词 | plusieurs avions；plusieurs fois |
| certain(e), certains, certaines | 某个、某些；单数常与 un(e) 连用 | certains auteurs；un certain auteur du 19e siècle |
| tout, toute, tous, toutes | 任何、整个、全部；随名词变化 | tout homme；toute la rue；toute une année；tous les dimanches |

课文里的 **plusieurs fois par semaine**、**certains trucs inutiles**、**quelques bonnes résolutions** 都保留后面的名词。下一课会进一步遇到不再跟名词的泛指代词，勿混在一起。

> 来源：[[你好法语2-11.23.pdf#page=74|教材第 74 页：chaque、quelque、plusieurs]]；[[你好法语2-11.23.pdf#page=75|第 75 页：certain、tout]]。

### 3. 课文里的代词与否定

- **on se souhaite une bonne année**：se 表“互相”，是间接宾语；une bonne année 是直接宾语。
- **je ne les respecte pas**：les 回指先前那些决定；**je n'en prends plus**：en 代替数量未确定的决定，ne…plus 表“不再”。
- **penser plus à soi**：soi 在这里表示泛指的“自己”。plus 在第 72 页有印刷发音对照：如 plus fort 为 [ply]，plus utile 联诵为 [plyz]，表示数量更多的 plus 可读 [plys]；按具体结构分辨，不把所有词尾 s 都读出。

> 来源：[[你好法语2-11.23.pdf#page=72|教材第 72 页：plus 发音注释]]；[[你好法语2-11.23.pdf#page=76|第 76 页：代词与搭配注释]]。

### 第四单元课件补充：用同一句话对照 si

| 课件例句 | 主句与语气 |
|---|---|
| S'il fait beau, je sors. | 直陈式现在时：天气好我就出门。 |
| S'il fait beau, je vais sortir. | 最近将来时：天气好我就准备出门。 |
| S'il fait beau, je sortirai. | 简单将来时：天气好我就会出门。 |
| S'il fait beau, sortons. | 命令式：天气好的话，我们就出门吧。 |
| S'il faisait beau, je sortirais. | 未完成过去时 + 条件式现在时：要是天气好，我就会出门。 |

- **Si j'étais toi, je ne ferais pas ça.** 我要是你，就不会这么做。**Si j'allais en France, je visiterais tous les musées célèbres.** 要是我去法国，就会参观所有著名的博物馆。两句都用假设结构，不必译成过去。
- **lire pour se cultiver**（阅读以增长见识）、**respecter la loi**（遵守法律）、**décider de voyager**（决定去旅行）。对照 **Je vous souhaite une très bonne année.**（祝您新年快乐。）与 **Je souhaite que ce soit une journée parfaite.**（我希望今天是完美的一天。）

> 课件：[[你好法语A2第四单元.pdf#page=2|第 2–3 页：词汇与搭配]]；[[你好法语A2第四单元.pdf#page=4|第 4–5 页：si 对照]]。[[你好法语A2第四单元.pdf#page=6|第 6 页]]是听力选项，不作答。第 3 页的 *Elle achètes* 是笔误，此处不当作变位范例。

## 快速复习

- Si j'avais le temps, j'aimerais…：假设从句用未完成过去时，主句用条件式。
- chaque année 是单数；plusieurs fois 是复数；certains trucs 后面仍有名词。
- prendre une résolution → la respecter；ne…plus = 不再。

# A2 Lesson 20 - Les études à l'étranger, une autre manière d'apprendre…

> [!info] 本课重点
> 读五位学生的留学经历，比较导师、选课、评分和学习负担；复习 **chaque fois que**、**ne… pas que** 和程度、数量比较。课文是个人经验，法国教育制度图也是教材的历史资料，不当作现行政策。

## 单词

| 法语 | 中文与批注 |
|---|---|
| le tutorat / suivre un étudiant | 导师辅导制／跟进学生的学习。对照 **suivre un cours**（修一门课）。 |
| le système éducatif / le système universitaire | 教育体系／大学教育体系；手写并列 **le système éducatif / médical**。 |
| une licence / une maîtrise | 学士层级学位／教材语境下的学位；旁注 **master** 是手写联想，不据此判断不同年代或地区的资历等同。 |
| à la carte / un redoublement | 自由选择／留级、重读。 |
| une note / noter / un examen | 分数／评分／考试。 |
| une matière / rendre un devoir | 科目／交作业。 |
| du travail personnel / obligatoire | 自主学习任务／必须完成的。 |
| un petit job / payer ses études | 零工／支付学习开支。 |
| une particularité / tolérant(e) | 特点／宽容的。 |

| 动词 | 现在时代表形式 | 过去分词 |
|---|---|---|
| rendre | je rends / il rend / nous rendons / ils rendent | rendu |
| suivre | je suis / il suit / nous suivons / ils suivent | suivi |

**rendre** 不只表示交还、上交。第 109 页手写例句（规范重音）：**Mes études à l'étranger me rendent plus compétent.** 留学让我更有能力。这里是 **rendre + 人 + 形容词**（使某人变得……），不同于 **rendre un devoir**。

> 来源：[[你好法语2-11.16.pdf#page=108|教材第 108 页：词汇、注释及手写联想]]；[[你好法语2-11.16.pdf#page=109|第 109 页：变位表与手写例句]]。

## 语法

### 1. chaque fois que：每次……的时候

**chaque fois que + 直陈式**。课文 **chaque fois qu'on a un problème** 是“每次遇到问题时”；教材另有 **Chaque fois qu'elle est de mauvaise humeur, elle me téléphone.**（她每次心情不好都会给我打电话。）que 在元音前缩成 **qu'**。

### 2. ne… pas que：不只是

**Il n'y a pas que les étudiants qui sont notés !** 不只是学生会被评分。对照 L18 的 **ne… que**（只）：加上 **pas** 就否定这一限制；后句 **Les étudiants notent aussi leurs professeurs.** 说明老师也会被评分。**sont notés** 是现在时被动，**notés** 跟复数主语 **les étudiants** 配合。

### 3. 数量与程度比较

- **plein de + 名词** 在这里相当于 **beaucoup de**，如 **plein de petits jobs**（许多零工）；作为数量表达，**plein** 不随名词变形。
- **beaucoup plus ouvert que le nôtre**：比我们的开放得多。**beaucoup** 加强 **plus ouvert**；**le nôtre** 替代 **notre système**。
- **plus de discussions / peu de cours / beaucoup de travail personnel**：比较或描述数量时，注意 **de + 名词**。**c'est plus facile qu'en France** 则是比较“容易”的程度。

> 来源：[[你好法语2-11.16.pdf#page=108|教材第 108 页：三条课文注释]]；[[你好法语2-11.16.pdf#page=109|第 109 页：比较表达]]。

## 快速复习

- chaque fois qu'on a un problème：每次遇到问题时。
- il n'y a pas que les étudiants…：不只是学生……
- rendre un devoir 与 rendre quelqu'un plus compétent：同一个动词，两种搭配。
- beaucoup plus ouvert que le nôtre 是程度比较，plus d'examens 是数量比较。
